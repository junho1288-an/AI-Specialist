DAY 2 / 빠른 복습

찾는 기준 → 참고 비율 → 정보 섞기

목적: 각 위치에 문맥을 반영한 새 벡터를 만든다. 뒤의 GPT 출력층이 이를 이용해 다음 토큰을 예측한다.

이름하는 일
Q · Query · 질의현재 위치가 찾는 특징
K · Key · 검색 단서각 위치가 매칭에 제시하는 특징
V · Value · 전달 정보비율에 따라 실제로 섞는 내용
Q, K, V = W_query(x), W_key(x), W_value(x)
scores = Q @ K.transpose(1, 2)
scores.masked_fill_(future_mask, -torch.inf)
weights = torch.softmax(scores / K.shape[-1]**0.5, dim=-1)
context = weights @ V

dropout=0인 단일 헤드 배치 예시. 세 Linear는 서로 다른 학습 파라미터를 사용하며 모든 토큰에 공유된다.

입력
(B,T,3)
Q·K·V
각 (B,T,2)
점수·비율
각 (B,T,T)
문맥 벡터
(B,T,2)

예시: 비율 [0.8,0.2], V₁=[10,0], V₂=[0,10] → 출력 [8,2]. Q·K를 고정하고 V만 바꾸면 비율은 같고 출력이 바뀐다.

  • 미래 mask: 다음 토큰 정답을 미리 보는 것을 막는다. 현재 위치 자신은 볼 수 있다.
  • softmax 전 점수와 후 비율을 구분한다. 비율은 어휘 전체의 다음 토큰 확률이 아니다.
  • dropout 전 비율 행 합은 1. 출력 벡터의 합이 1일 필요는 없다.
  • 여러 헤드는 여러 투영 공간에서 같은 계산을 하고 결과를 합친다.

Chapter 3 inputs는 설명용 수동 벡터. 랜덤 Q·K·V에 의미 있는 문법 역할을 단정하지 않는다. Wrapper d_out은 헤드당 폭, 통합 구현 d_out은 전체 폭이다.
