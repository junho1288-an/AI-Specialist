토큰 번호를 벡터로 바꾸기

토큰 ID를 실수 벡터에 대응시키는 학습 가능한 표. encode가 만든 ID를 입력으로 받는다.

layer = torch.nn.Embedding(vocab_size, output_dim)
vectors = layer(input_ids)

예: Embedding(6,3), ID [2,3,5,1] → 표 (6,3), 출력 (4,3). 유효 ID는 0~5. 같은 표의 같은 ID는 같은 행. manual_seed는 초기 난수 재현을 돕고 학습을 수행하지 않는다.
