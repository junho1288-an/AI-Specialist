과제를 시도한 뒤 펼치는 참고 자료

배치를 유지하며 펼치기

이번 연습에서 N은 이미지 수, C는 채널 수, H와 W는 높이와 너비입니다. (N, C, H, W)를 (N, C × H × W)로 펼칩니다.

import torch
x = torch.zeros(2, 1, 28, 28)
flat = x.flatten(start_dim=1)
print(x.shape, flat.shape)
assert flat.shape == (2, 784)
assert x.numel() == flat.numel()

start_dim=1은 첫 번째 배치 축을 남기고 그다음 축부터 합칩니다. 전체를 펼치면 이미지 사이의 구분까지 합쳐지므로 목표 shape와 달라집니다.
