DAY 3 / 시도 후 확인하는 한 장 요약

RGB → 특징판 → 10개 점수

기준: 실습의 CIFAR용 ResNet18. 강의 그림은 B=배치, C=채널, W=가로, H=세로 순서인 (B,C,W,H)로 읽는다. 실제 PyTorch 입력은 (B,C,H,W)다. 이 예시는 W=H라 수치가 같다. 예: W=40,H=24이면 강의 도식 (B,3,40,24), 실제 텐서 (B,3,24,40).

단계출력 shape의미
PIL RGB 배열 관점(32,32,3)이미지 한 장, 채널 마지막
ToTensor·Normalize(3,32,32)채널 우선, 숫자 범위 변환
DataLoader(B,3,32,32)이미지 B장
conv1(B,64,32,32)3×3, s=1,p=1
bn1·relu·Identity(B,64,32,32)shape 유지
layer1(B,64,32,32)기본 블록 2개
layer2(B,128,16,16)첫 블록 stride=2
layer3(B,256,8,8)첫 블록 stride=2
layer4(B,512,4,4)첫 블록 stride=2
avgpool(B,512,1,1)각 채널 공간 평균
flatten(x,1)(B,512)배치 보존
fc Linear(512,10)(B,10)클래스별 logits
softmax(dim=1)(B,10)이미지마다 확률 합 1
max(dim=1)conf·pred 각각 (B,)최대 확률·클래스 번호
CrossEntropyLoss()logits (B,10)와 labels (B,)로 평균 손실

예시: B=4면 마지막 logits는 (4,10), pred는 (4,). 64·128·256·512는 특징 채널 수, 10은 클래스 수다.

  • Conv weight: 첫 레이어 (64,3,3,3). 출력 특징판 (B,64,32,32)와 다르다.
  • 출력 공간 크기: dilation=1이면 ⌊(입력+2padding−kernel)/stride⌋+1.
  • skip 덧셈은 shape 유지. 크기 변경 시 1×1 Conv·BN으로 우회 경로도 맞춘다.
  • FC weight=(10,512). features @ weight.T + bias로 logits를 만든다.
  • 학습 loss에는 softmax 전 logits. labels는 클래스 번호 int64 텐서다.
