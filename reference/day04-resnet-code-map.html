이론을 어떤 코드로 쓰나요?

9단계 수업으로 돌아가기 · 전체 shape 표

현재 실습은 CIFAR용 ResNet18입니다. 코드의 실제 축은 B,C,H,W이며, 강의 그림의 B,C,W,H 표기와 구분합니다. 아래는 예시 답안의 핵심이므로 먼저 문제를 시도한 뒤 읽으세요.

시험 범위 업데이트: 원본 노트북 6) 성능 분석(전체 셀 17)까지 포함합니다. 아래 1~9단계는 HTML 설명 번호이며 모두 범위 내 내용에 연결됩니다. 원본 7번 이후 시각화·Grad-CAM·Receptive Field·t-SNE·ONNX는 제외합니다.

한 예시로 다시 연결

RGB 8장 → (8,3,32,32) → 특징 추출 (8,512,4,4) → 채널별 평균 (8,512,1,1) → flatten (8,512) → FC logits (8,10). 정답 labels는 (8,) long입니다. loss에는 raw logits를 넣고, 예측 클래스는 logits.argmax(dim=1)로 구합니다.

혼동하기 쉬운 것

  • Normalize는 shape를 바꾸지 않습니다. train/test 모두 같은 mean·std를 사용합니다.
  • residual 덧셈은 concat과 다릅니다. 채널 수를 더하지 않습니다.
  • eval은 모듈 동작, no_grad는 gradient 기록을 제어합니다.
  • 마지막 배치가 작으면 loss 평균은 샘플 수로 가중해야 합니다.
  • 혼동행렬은 행=실제 라벨, 열=예측입니다.
