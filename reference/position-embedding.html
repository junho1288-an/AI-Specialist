토큰 정보에 위치를 더하기

토큰 벡터에 위치 벡터를 더한다. RoPE 회전과 구분한다.

positions = torch.arange(max_length)
pos_embeddings = pos_embedding_layer(positions)
input_embeddings = token_embeddings + pos_embeddings

예: inputs (8,4) → token (8,4,256), position (4,256), 합계 (8,4,256). 위치마다 256차원 벡터를 모든 배치에 공통 적용한다. 어휘 크기 50257은 데이터 토큰 수가 아니다.
