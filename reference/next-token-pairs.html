DAY 01 / 두 번째 실습 요약

파일 → 텍스트 → ID → x·y

  • os.makedirs("datas", exist_ok=True): 폴더 준비.
  • if not os.path.exists(...): 파일이 없을 때만 다운로드.
  • response.raise_for_status(): HTTP 오류 확인.
  • "wb": 바이트 쓰기. "r", encoding="utf-8": 문자열 읽기.
  • tokenizer.encode(raw_text): 문자열을 ID 리스트로. 길이는 토큰 수.
  • enc_text[50:]: 앞의 50토큰을 건너뛰고 인덱스 50부터 끝까지.
sample = [10, 20, 30, 40, 50]
context_size = 4
x = sample[:context_size]       # [10,20,30,40]
y = sample[1:context_size + 1]  # [20,30,40,50]

시작 포함, 끝 제외. y의 양쪽 인덱스를 +1 해야 같은 길이로 다음 토큰을 가져온다. 정답은 원본 데이터에서 얻는다. 현재 위치의 모델은 앞부분과 현재 토큰을 보고 다음 토큰을 예측하며, 미래를 가리는 마스크는 모델 쪽에서 적용한다.

예: a b c d e → x는 a b c d, y는 b c d e. 원본은 최소 context_size+1토큰이 필요하다.
