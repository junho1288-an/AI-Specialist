DAY 01 / 세 번째 실습 요약

만들기 · 세기 · 꺼내기

  • __init__: 텍스트를 토큰화하고 입력·정답 쌍을 텐서로 저장.
  • __len__: 저장한 샘플 수 반환.
  • __getitem__(idx): 같은 idx의 입력·정답 반환.
  • max_length: 샘플 하나의 토큰 개수.
  • stride: 다음 샘플 시작점으로 움직이는 간격.
for i in range(0, len(token_ids) - max_length, stride):
    input_chunk = token_ids[i:i + max_length]
    target_chunk = token_ids[i + 1:i + max_length + 1]
    self.input_ids.append(torch.tensor(input_chunk))
    self.target_ids.append(torch.tensor(target_chunk))

def __len__(self):
    return len(self.input_ids)

def __getitem__(self, idx):
    return self.input_ids[idx], self.target_ids[idx]

예시: 원본이 [10,20,30,40,50,60,70,80,90], 길이=4, stride=2라면 i는 0·2·4, 샘플은 3개다. dataset[1]은 i=2에서 만든 입력 [30,40,50,60]과 정답 [40,50,60,70]이다.

i는 원본 시작점, idx는 저장한 샘플 번호다. target은 이미 +1 되어 있으므로 __getitem__에서는 두 리스트에 같은 idx를 쓴다. 원본은 최소 길이+1토큰이 필요하고, stride와 길이는 양의 정수를 사용한다.
