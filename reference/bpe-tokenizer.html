DAY 01 / 시도 후 확인하는 한 장 요약

문자열 ↔ 토큰 ID

  • 토큰: 텍스트 처리 단위. 단어와 항상 일치하지 않는다.
  • BPE: Byte Pair Encoding. 자주 붙는 조각을 합치는 규칙을 학습한다. 지금 실습은 이미 배운 GPT-2 규칙을 사용한다.
  • 토큰 ID: 어휘표의 식별 번호. 중요도·글자 수·의미 점수가 아니다.
  • encode: 문자열 → 토큰 ID 리스트.
  • decode: 토큰 ID 리스트 → 문자열.
import tiktoken
tokenizer = tiktoken.get_encoding("gpt2")
text = "Hello,"
ids = tokenizer.encode(text)  # [15496, 11]
assert tokenizer.decode(ids) == text

원문에 <|endoftext|>가 있으면 이 실습에서는 allowed_special={"<|endoftext|>"}을 encode에 전달한다. get_encoding의 인자는 인코딩 이름이다. integers라는 변수명은 바꿔도 되지만 ID를 다음 decode에 동일하게 전달해야 한다.

예: "a" "b"는 공백 없이 "ab"가 된다. decode는 문법·띄어쓰기를 교정하지 않는다.
