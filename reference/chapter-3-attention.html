CHAPTER 3 / 시도 후 확인

미래 가리기와 여러 헤드

단일 헤드

keys = self.W_key(x)
queries = self.W_query(x)
values = self.W_value(x)
scores = queries @ keys.transpose(1, 2)
scores.masked_fill_(self.mask.bool()[:T, :T], -torch.inf)
weights = torch.softmax(scores / keys.shape[-1]**0.5, dim=-1)
weights = self.dropout(weights)
context = weights @ values

입력 (B,T,d_in) → Q·K·V (B,T,d_out) → scores·weights (B,T,T) → context (B,T,d_out). 예: (2,6,3) → (2,6,2). 마스크는 자기 위치까지 허용하고 미래만 차단한다. 합이 1인 가중치는 dropout 전을 말한다.

두 Multi-Head 구현 비교

구현d_out출력
Wrapper헤드 하나의 차원(B,T,H×d_out)
통합 구현전체 출력 차원(B,T,d_out)

예: Wrapper(d_out=2,H=2)는 4차원, 통합(d_out=2,H=2)은 헤드당 1차원·전체 2차원이다. 원본 셀 4의 저장 출력 4는 현재 코드와 맞지 않는다.

# 통합 구현: D는 전체 d_out, h는 D // H
(B,T,D) → view(B,T,H,h) → transpose → (B,H,T,h)
scores = Q @ K.transpose(2,3)       # (B,H,T,T)
context = weights @ V              # (B,H,T,h)
context.transpose(1,2).contiguous().view(B,T,D)
# 마지막 out_proj도 (B,T,D)를 유지

ModuleList는 헤드 모듈 등록, cat은 마지막 축 연결, contiguous는 transpose 후 view를 위한 메모리 배치 준비다. 마스크는 register_buffer로 등록되며 학습 파라미터가 아니다.

코드 조각의 T, B, H, D, h는 shape를 설명하는 기호다. 실제 전체 코드는 각 수업을 참고한다.
