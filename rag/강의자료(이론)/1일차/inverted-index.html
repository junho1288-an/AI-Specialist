Inverted Index와 Term-Document Matrix

같은 document collection을 두 가지로 표현합니다. inverted index의 posting은 freq와 offset list를 담고, matrix의 cell은 freq만 담습니다. 아무 항목에나 마우스를 올리거나 눌러 보면 세 곳에서 대응하는 부분이 함께 표시됩니다.

offset 단위

문장을 직접 고쳐 보세요. 각 token 아래 숫자가 offset입니다. 예제의 d1과 d2는 같은 term을 다른 순서로 씁니다.

Inverted Index

term, df → ⟨docID, freq, [offset, …]⟩ → …

dictionary의 각 term이 posting list를 가리킵니다. 그 term이 나오는 document마다 posting이 하나씩 있고, freq는 offset list의 길이와 같습니다.

Term-Document Matrix

  • row (term)그 term의 posting list. 0이 아닌 cell마다 posting이 하나 있습니다.
  • cell 값posting의 freq. offset list는 들어갈 자리가 없습니다.
  • column (document)그 document의 bag of terms. 어떤 term이 몇 번 나왔는지만 남습니다.

Document를 되살릴 수 있는가

Inverted index에서: 복원됩니다

모든 posting list에서 이 document의 posting만 모아, 각 term을 offset이 가리키는 slot에 놓습니다.

Matrix의 column에서: 순서를 알 수 없습니다

column에서 얻는 것은 term과 frequency가 전부입니다.

inverted index에서 복원되는 것은 tokenization을 거친 document입니다. case, punctuation, 그리고 stopword 제거나 stemming으로 버린 정보는 돌아오지 않습니다.

TF-IDF Ranking

term-document matrix는 formal model입니다. document와 query를 같은 term 공간의 vector로 놓고, score를 두 vector 연산으로 정의합니다. inverted index는 그 score를 실제로 계산하는 data structure이고, posting만 읽어서 같은 값을 얻습니다.

w(t,d) = tf(t,d) × idf(t) idf(t) = log10( N / df(t) )
score

Matrix: score의 정의

cell에 tf 대신 weight w를 넣습니다. column 하나가 document vector, 오른쪽 q column이 query vector이고, score는 document column과 q column의 dot product입니다.

Inverted index: term-at-a-time 계산

index 구조는 그대로입니다. dictionary의 df에서 idf를, posting의 freq에서 tf를 얻어 query 시점에 weight를 계산합니다. 추가로 두는 것은 document length |d| table 하나입니다. offset list는 ranking 계산에 쓰지 않습니다.

Ranked list

weight w를 posting에 미리 저장하지 않는 이유는 document가 하나 추가될 때마다 N과 df가 바뀌어 idf가 전부 달라지기 때문입니다. tf와 df만 저장하면 index를 고치지 않아도 됩니다. query vector의 길이 |q|는 모든 document에 똑같이 곱해지므로 ranking에 영향이 없어 생략했습니다.
