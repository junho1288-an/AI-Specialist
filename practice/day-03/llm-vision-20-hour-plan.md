# LLM·Vision 20시간 집중 학습 가안

2026-11-04 사용자가 제시한 시간: 내일 4시간 + 토요일 10시간 + 일요일 6시간 = 20시간. 요청한 세 구간만 배정한다. 집중 학습 기준이며 휴식·설치·다운로드·긴 학습 실행을 포함하면 실제 학습량은 줄어든다.

## 현실적인 목표

**시험 형식 추가 확인:** 사용자는 `????` 빈칸 채우기 또는 주어진 class·function의 일부 코딩이라고 구체화했다. 이 기준이면 20시간을 **전 범위의 핵심 빈칸·부분 구현을 한 번 훑고 오답을 교정하는 집중 대비 기간**으로 잡을 수 있다. 전체 코드 독립 구현 예상 시간을 시험 준비에 그대로 적용하지 않는다. 단, 실제 첫 연습 결과 전이므로 충분함·합격을 보장하지 않는다.

20시간의 목표는 **핵심 코드 흐름·shape를 이해하고, 제공된 코드의 빈칸과 부분 구현을 연습하며, 모든 모델의 입출력 차이를 연결하는 것**이다. 전체 노트북의 모든 줄을 완전 숙달한 것으로 취급하지 않는다. 기존 시간 배분은 유지하되 “재작성”은 전체 프로그램 구현 대신 해당 빈칸·처리 구간을 다음날 다시 풀기로 바꾼다.

확인한 Vision 파일: ResNet18 29셀, ViT 31셀, DETR 34셀, U-Net 15셀. 시각화·설치·재사용 학습 루프도 포함되므로 파일 길이를 그대로 새 학습량으로 보지는 않는다. ResNet 전처리·loss·optimizer는 다른 모델과 재사용되고, LLM Attention은 ViT 이해로 연결된다. DETR·U-Net은 분류와 출력·정답 구조가 달라 별도 학습이 필요하다.

## 시간 배분

| 구간 | 내용 | 목표 |
| --- | --- | --- |
| 내일 2시간 | ResNet 전처리·Conv·잔차·FC shape | RGB → (B,10) → pred (B,) 설명 |
| 내일 2시간 | 공통 학습·평가 루프 | logits·labels·loss·역전파·갱신·eval 연결 |
| 토요일 2시간 | LLM Chapter 3 Attention | QKV·mask·softmax·V 가중합, 작은 forward 작성 |
| 토요일 2시간 | Chapter 4 GPT | 블록·임베딩·logits·생성 흐름 연결 |
| 토요일 2시간 | Chapter 5·6 사전학습·분류 | 공통 학습 루프 재사용, next-token loss와 분류 loss 비교 |
| 토요일 2시간 | Vision ViT | patch → token → Transformer → 클래스 출력 |
| 토요일 2시간 | 자료 없이 재작성·오답 교정 | 기존 설명을 다시 읽는 대신 실제 구현 확인 |
| 일요일 2시간 | U-Net | encoder·decoder·skip concat·픽셀별 예측·mask 정답 |
| 일요일 1시간 | DETR | 전처리·박스 좌표 변환·클래스/박스 출력·필터링 첫 이해 |
| 일요일 30분 | LoRA | 원래 W 고정·저랭크 변화량·학습 대상 개념 첫 이해 |
| 일요일 30분 | 교안 PDF 코드 조각 복습 | 전처리 등 핵심 API·인자·shape 확인 |
| 일요일 2시간 | LLM·Vision 혼합 함수 문제 | 약점을 드러내고 후속 학습 목록 만들기 |

합계 20시간. 이 속도로 각 장 전체를 숙달한다는 뜻이 아니라 선택한 핵심을 압축해서 다루는 계획이다. 예를 들어 DETR 1시간은 박스 출력 흐름의 첫 이해이며, Transformer 전체·hook 시각화 구현 완료를 뜻하지 않는다. LoRA 30분도 개념 소개이며 독립 구현 숙달은 아니다.

## 우선순위와 완료 기준

- 먼저: 데이터·정답 shape, 주요 forward, loss, 학습/평가·예측 함수. 단순 API 이름 암기 대신 인자와 반환 조건을 확인한다.
- 다음: confusion matrix·평가 지표, LoRA·교안 코드 조각의 관련 부분. 실제 강사 강조에 따라 시간을 재조정한다.
- 후순위: Grad-CAM·attention 인터랙티브 UI·t-SNE·ONNX·플롯 꾸미기 상세 구현. **시험 제외라는 뜻은 아니며** 시간이 부족해 늦추는 항목이다.
- 긴 모델 학습은 학습 시간 측정에서 분리한다. 작은 합성 텐서나 제공 데이터로 forward·loss와 함수 내부를 먼저 확인한다.
- 매 구간 마지막에는 shape 한 문제, 빈칸 또는 주어진 함수의 부분 구현 한 문제로 확인한다. 미통과면 다음 세부 주제로 넘어가기보다 그 오류를 먼저 교정한다.

예시: 분류 logits=(B,10), labels=(B,); 언어 모델 logits=(B,T,V), targets=(B,T); 분할은 이미지 전체 번호 하나가 아니라 픽셀별 정답이 필요하다. 실제 U-Net·DETR 출력 shape는 해당 코드 설정을 읽고 확인한다.

현재 이해도는 설명 요청·일부 제출로만 확인됐고 지연 인출은 충분히 검증하지 않았다. 첫 4시간의 재작성 결과를 보고 이후 시간을 조정한다. 근거: [시험 출제 기준](../../EXAM-SCOPE.md), `vision/*.ipynb` 네 파일의 섹션·함수 목록, LLM Chapter 3~6, [Day 3 노트](../../class-notes/day-03.md).
