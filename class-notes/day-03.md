## 수업 중 메모

### train_tfms·T·Compose 뜻

- `tfms`는 `transforms(변환들)`를 줄여 쓴 변수 이름이다. `train_tfms`는 학습 이미지에 적용할 전처리·증강 묶음이며 Python 예약어나 필수 이름은 아니다.
- `T`는 실습 셀 4의 `import torchvision.transforms as T`에서 정한 별명이다. `T.ToTensor()`는 `torchvision.transforms.ToTensor()`와 같은 대상을 가리킨다. torch 자체의 별명은 아니다.
- `Compose(합성·조합)`는 전달한 변환 목록을 위에서 아래 순서로 적용하는 도구다. `T.Compose([...])`로 만들고 `train_tfms(image)`로 적용한다. Dataset의 transform 인자로 넣으면 샘플을 꺼낼 때 호출된다.
- **예시:** image → RandomCrop(32,padding=4) → RandomHorizontalFlip → ToTensor → Normalize → 최종 텐서. Compose 생성 시 이미지를 바로 바꾸는 것이 아니라 변환 순서를 준비한다.

### 강의 그림의 축 순서

- 사용자 요청에 따라 ResNet 수업 도식은 **Batch × Channel × Width × Height(배치·채널·가로·세로)** 순서로 읽도록 표시했다. 실제 PyTorch Conv2d·ToTensor의 축은 BCHW·CHW이므로 별도 안내한다.
- **예시:** CIFAR-10은 32×32라 두 순서의 숫자가 같지만 가로 40·세로 24이면 강의 도식 (B,3,40,24), 실제 코드 텐서 (B,3,24,40)이다. 실제 코드에 표기 변경만을 위한 transpose를 추가하지 않는다.

### ResNet18: 데이터에서 10클래스 예측까지

- [9단계 그림·shape 수업](../lessons/0028-day03-resnet18-shape-journey.html)을 만들었다. 매 단계 입력·출력 shape와 즉시 확인 문제를 제공하고, 맨 위 이미지 단계부터 진행한다. [복습표](../reference/day03-resnet18-shapes.html), [함수 구현 과제](../practice/day-03/resnet-shape-check.md)도 연결했다.
- 실습 모델은 첫 Conv가 3×3·stride=1이고 MaxPool이 Identity다. **예시:** B=2 입력 (2,3,32,32) → (2,64,32,32) → (2,128,16,16) → (2,256,8,8) → (2,512,4,4) → 평균·flatten (2,512) → FC (2,10) → pred (2,).
- 노트북 셀 9의 실제 빌더로 합성 입력 forward·우회 경로·출력 확률 shape를 확인했다. 원문 PDF 18~23·36~40쪽과 구조를 연결했으며, ImageNet 표의 224×224·1000클래스와 구분한다. 전체 학습·사용자 숙달은 미확인이다.

- ResNet18·CIFAR-10 실습을 시작한다. 노트북 29개 셀의 구성과 함수 목록을 확인했다. 데이터 전처리 → 모델 구성 → 학습·평가 → 추론 → 성능 분석·시각화 순서이며, 추가 실습은 receptive field·t-SNE·ONNX다. 노트북 전체를 실행한 것은 아니다.
- 질문은 해당 코드의 역할·파라미터·입출력 shape와 짧은 예시로 설명한다. **예시 질문:** `train_one_epoch의 optimizer.zero_grad()는 왜 필요한가?`처럼 함수·코드를 지정하면 그 부분에 맞춰 답한다.

- **예시:** 제공된 `(B,T,D)` Q/K에서 attention scores를 만드는 빈칸을 채우고, `(B,T,T)` shape와 미래 토큰 차단 여부를 확인한다. 모델을 통째로 외워 작성하기보다 빠진 연산·축·처리 구간을 완성한다.
- 각 문제는 공통 준비 셀 이후 독립 실행 가능하며, 정답은 공개하지 않았다. 다운로드 없이 합성 데이터로 풀이한다. LLM 마지막 2문항은 Chapter 7 지시 학습·DPO 확장이다. 제출 뒤 오답을 기준으로 다음 수업일·3/7수업일 후 복습하며 현재 숙달 판정은 하지 않는다.

- **시험 형식 구체화:** `????` 빈칸 채우기 또는 제공된 class·function의 일부 코딩(사용자 전달). 전체 프로그램을 맨땅에서 구현하는 것이 기본 출제 형식은 아니다. 20시간 계획도 핵심 빈칸·부분 구현과 오답 반복에 맞춘다.
- **예시:** `attn_scores = queries @ keys.????(1,2)`에서 shape가 (B,T,D) @ (B,D,T)가 되어야 함을 보고 필요한 메서드를 고르는 연습이다. 답을 맞혔어도 인자·축을 바꾼 문제에서 이해를 다시 확인한다.
