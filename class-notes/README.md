# 매일 수업 필기

수업 필기는 이 폴더의 `day-01.md`부터 `day-12.md`까지 작성한다. 날짜는 파일 안에 적고, 번호는 실제 수업 순서로 센다. 쉬는 날에는 번호를 올리지 않는다.

## 시작하기

1. 첫날은 [day-01.md](day-01.md)를 연다.
2. 다음 수업부터는 [_template.md](_template.md)를 복사해 `day-02.md`처럼 이름을 붙인다.
3. 날짜와 수업 주제를 적고, 아는 만큼만 채운다. 모르는 부분은 질문으로 남겨도 된다.

VS Code에서는 Markdown 파일을 열고 `Ctrl+Shift+V`로 미리보기를 볼 수 있다.

## 수업 중에는 빠르게

- 강사의 설명을 내 말로 짧게 적는다. 정리가 안 되면 우선 `수업 중 메모`에 적는다.
- 교안 파일명과 페이지, 노트북 이름과 셀 제목을 함께 남긴다. 나중에 시험 범위를 찾는 기준이 된다.
- 코드는 실행하는 `.ipynb`에 작성하고 필기에는 파일 경로와 핵심 코드의 이유를 적는다.
- 이해되지 않는 부분에는 `?`, 강사가 시험 관련으로 강조한 부분에는 `시험 언급:`을 붙인다. 내 예상과 강사의 말을 구분한다.

## 수업 후에는 10분 정리

1. 핵심 내용을 내 말로 3줄 적는다.
2. 오늘 코드가 실행되는 순서와 중요한 텐서의 shape를 적는다. 아직 다루지 않았다면 비워 둔다.
3. 자료를 닫고 오늘 배운 작은 기능 하나를 빈 셀에 다시 작성한다.
4. 성공 여부, 참고한 도움, 오류와 수정 이유를 기록한다.
5. 다음 수업일·3수업일 후·7수업일 후 복습할 주제를 고른다. 과정 이후 복습도 남겨 둔다.

필기를 완벽하게 꾸미는 것보다 직접 설명하고 재작성한 결과를 남기는 데 시간을 쓴다. 체크는 실제 시도한 뒤 표시한다.

## 노트북과 연결하기

```text
class-notes/day-01.md             # 수업 필기와 질문
practice/day-01/tensor-shapes.ipynb # 직접 실행할 연습 코드의 권장 경로
```

원본 교안·실습 파일은 원래 이름과 내용을 보존한다. 필기에서 상대 경로로 연결하고, 과제 코드는 별도 노트북에 작성한다. 위 노트북 경로는 작성 위치의 예시이며 파일이 자동으로 생성된 것은 아니다.
