# Dataset 구성과 임베딩 shape의 코드 증거

2026-11-03 제출한 `practice/day-02/chapter-02-final.ipynb`에서 입력·다음 토큰 정답 슬라이싱, 텐서 저장, 같은 idx의 쌍 반환이 정확했다. 고정 토큰 경계 검사와 실제 실행에서 임베딩 `(6,3) → (4,3)`, 배치·위치 합산 `(8,4,256)`도 확인했다. 이는 제출 코드의 정확성 증거이며 독립 작성·지연 인출·구두 이해를 확인한 것은 아니다.

다음 지도는 같은 설명을 반복하기보다 함수 인자 전달, `[:50]`와 `[50:]` 구분, drop_last 예측부터 확인한다. 전역 text를 잘못 읽는 helper 오류와 제외 범위는 `practice/day-02/chapter-02-final-feedback.md`, `EXAM-SCOPE.md`를 참고한다.
