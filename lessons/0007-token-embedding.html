토큰 번호를 벡터로 바꾸기

교안 코드를 이해하고, 설명을 닫은 뒤 빈 노트북에 직접 작성합니다.

교안 기반 자체 연습입니다. 실제 출제 여부는 강사 공지를 따릅니다.

전체 목차이전 수업시험 문제복습 카드

1. ID는 표의 행 번호입니다

입력 ID[2,3,5,1]
→
Embedding(6,3)6행 × 3열의 학습 가능한 표
→
출력 벡터행 2·3·5·1을 꺼내 (4,3)

임베딩(embedding)은 토큰 ID를 여러 실수로 이루어진 벡터에 대응시키는 것입니다. ID가 2이면 임베딩 표의 2번 행을 꺼냅니다. 토큰화와 달리 이 단계에서는 모델이 사용할 학습 가능한 값을 준비합니다.

예시: 설명용 표에서 2번 행이 [0.7,0.8,0.9]라면 ID 2의 출력은 바로 그 벡터입니다. ID에 3을 곱하는 계산이 아닙니다.

행 번호를 골라 보기

선택한 벡터: [0.7,0.8,0.9]

값은 설명용으로 정한 고정 표입니다. 교안의 실제 무작위 초기화 값이 아닙니다.

2. 교안의 세 빈칸 채우기

import torch

input_ids = torch.tensor([2, 3, 5, 1])
vocab_size = 6
output_dim = 3

torch.manual_seed(123)
embedding_layer = torch.nn.Embedding(vocab_size, output_dim)
print(embedding_layer.weight)

token_embeddings = embedding_layer(input_ids)
print(token_embeddings)
빈칸답이유
Embedding의 첫 인자vocab_size가능한 토큰 ID가 몇 종류인지. 6이면 0~5.
Embedding의 둘째 인자output_dim각 토큰을 몇 개 실수로 나타낼지. 3이면 3차원.
embedding_layer의 입력input_ids꺼낼 행 번호들을 담은 정수 텐서.

embedding_layer.weight의 shape는 (6,3), 출력은 (4,3)입니다. torch.tensor([2,3,5,1])은 기본적으로 이 정수 ID 용도에 맞는 int64 텐서가 됩니다.

3. 외울 것은 숫자 값보다 모양

torch.manual_seed(123)은 난수 시드를 정해 같은 조건에서 초기값 재현을 돕습니다. 이 줄이 학습을 수행하거나 seed=123이라는 정답 벡터를 만드는 것은 아닙니다. 실제 숫자는 환경·실행 순서 등의 영향을 받을 수 있습니다.

이 표는 처음에는 무작위로 초기화됩니다. 이후 학습 과정에서 갱신되며, 지금 셀에서는 아직 학습하지 않습니다. ID의 숫자 크기가 의미의 크기를 나타내는 것도 아닙니다.

같은 시점의 같은 임베딩 표에서 ID 2를 두 번 조회하면 같은 행이 나옵니다. 반면 뒤에 배울 위치 임베딩을 더하면 같은 ID여도 위치에 따른 최종 입력은 달라질 수 있습니다.

교안에 저장된 값으로 확인

저장된 표의 ID 2 행은 [1.2753,-0.2010,-0.1606]이고 출력의 첫 행도 같습니다. 이 수치는 저장된 실행 결과이며 여기서 재계산한 값은 아닙니다. 핵심은 행을 조회한다는 동작입니다.

교안: 여섯 번째 코드 셀 · torch.nn.Embedding. API 근거: PyTorch Embedding 공식 설명.

설명을 가리고 풀어 보기

1~5번 자동 확인, 6번 설명 비교, 7번 직접 코딩. 브라우저에서는 Python을 실행하지 않으며 답변을 저장·전송하지 않습니다.

01 · 행 개수

embedding_layer = torch.nn.Embedding(????, output_dim)

시도 후 정답·해설

vocab_size. 예: vocab_size=6이면 0~5번 행을 가진 표입니다.

02 · 벡터 길이

embedding_layer = torch.nn.Embedding(vocab_size, ????)

시도 후 정답·해설

output_dim. 예: output_dim=3이면 각 토큰이 실수 3개로 표현됩니다.

03 · 조회할 행 번호

token_embeddings = embedding_layer(????)

시도 후 정답·해설

input_ids. 예: [2,3,5,1]을 넣으면 그 순서대로 표의 행을 꺼냅니다.

04 · 출력 shape

ID 4개를 Embedding(6,3)에 넣으면 출력 shape (4, ????)의 빈칸은?

시도 후 정답·해설

3. 토큰 4개 각각을 3차원 벡터로 바꿔 (4,3)입니다.

05 · ID 범위

“Embedding(6,3)에 ID 6을 넣어도 된다.”

시도 후 정답·해설

X. 행 번호는 0~5입니다. ID 6은 범위를 벗어납니다.

06 · 내 말로 설명하기

같은 input_ids 안에 ID 1이 두 번 들어 있으면 이 임베딩 셀의 두 출력 벡터는 같을까요? 왜일까요?

작성 후 비교할 해설

같은 시점의 같은 표에서 같은 행을 조회하므로 같습니다. 예: [1,1]은 1번 행을 두 번 꺼냅니다. 이 설명은 위치 정보 등을 더하기 전의 순수 임베딩 조회에 해당합니다.

07 · 빈 노트북 실기

제출 위치: practice/day-01/token-embedding.ipynb. 폴더와 파일은 직접 만드세요. 예상 5분, PyTorch가 설치된 환경에서 진행합니다.

Embedding(4,2)와 정수 ID [1,1,0]을 준비해 임베딩하세요. 표 shape, 출력 shape와 반복 ID의 결과를 검사하고, 허용되는 최대 ID를 말해 보세요.

시도 후 모범 코드
import torch

torch.manual_seed(123)
layer = torch.nn.Embedding(4, 2)
ids = torch.tensor([1, 1, 0])
vectors = layer(ids)
print(layer.weight, vectors)
assert tuple(layer.weight.shape) == (4, 2)
assert tuple(vectors.shape) == (3, 2)
assert torch.equal(vectors[0], vectors[1])
assert torch.equal(vectors[2], layer.weight[0])

최대 ID는 3입니다. 값 자체를 외우지 말고 표에서 어느 행을 꺼냈는지 설명하세요.
