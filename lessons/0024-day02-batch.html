DAY 02 / BATCH / 읽기 5분 + 연습 5분

배치는 ‘몇 개씩 묶을까?’

샘플 하나가 문제 한 개라면,
배치 하나는 한 번에 꺼내는 문제 묶음입니다.

학생 예시교안 토큰 예시마지막 묶음실행 코드확인 문제

1. 학생 10명에게 시험지를 나눠 준다면

학생 한 명을 샘플 하나라고 생각해 보세요. 전체 학생 10명이 Dataset입니다. 한 번에 3명씩 부르면 batch_size=3입니다.

전체: [A,B,C,D,E,F,G,H,I,J]

첫 배치: [A,B,C]     3명
둘째 배치: [D,E,F]   3명
셋째 배치: [G,H,I]   3명
마지막 배치: [J]     1명
batch_size=3은 ‘배치가 3개’라는 뜻이 아닙니다.
배치 하나에 최대 3명씩 담겠다는 뜻입니다. 이 예에서는 작은 마지막 묶음까지 총 4배치입니다.

Dataset은 학생 명단, DataLoader는 명단에서 몇 명씩 어떤 순서로 부를지 정해 주는 도구라고 기억하세요.

2. 이미지라면 한 장이 한 샘플

손글씨 이미지 5장이 있고 batch_size=2라면 2장·2장·1장으로 꺼냅니다. 한 이미지가 (채널 1, 높이 28, 너비 28)이라면 첫 배치의 입력 shape는 (2,1,28,28)입니다.

맨 앞 2는 이미지 개수이고, 뒤의 (1,28,28)은 이미지 한 장의 모양입니다. 배치 크기를 바꾼다고 이미지의 가로·세로 크기가 바뀌는 것은 아닙니다.

3. 지금 교안에서는 토큰 4개짜리 조각이 한 샘플

샘플 하나는 입력 x와 그에 대응하는 정답 y를 함께 가집니다. 아래 숫자는 원리를 보기 위한 토큰 ID입니다.

샘플입력 x정답 y
0[10,20,30,40][20,30,40,50]
1[20,30,40,50][30,40,50,60]

이 두 샘플을 batch_size=2로 묶으면 입력 두 개는 inputs에, 정답 두 개는 targets에 같은 순서로 쌓입니다.

inputs = [[10,20,30,40],
          [20,30,40,50]]   # shape (2,4)

targets = [[20,30,40,50],
           [30,40,50,60]]  # shape (2,4)
샘플 하나입력 (4,), 정답 (4,)
→
두 개씩 묶기batch_size=2
→
한 배치inputs (2,4)
targets (2,4)
설정세는 것이 예시
batch_size한 묶음의 샘플 수2개
max_length한 샘플의 입력 토큰 수4개
stride원본에서 다음 샘플 시작점으로 이동하는 간격1칸

배치에 입력 ID가 총 8개 있어도 배치 크기는 2입니다. 입력 2개와 정답 2개가 있다고 배치 크기를 4라고 세지도 않습니다. 입력·정답 한 쌍이 샘플 하나입니다.

4. 마지막 한 개는 어떻게 할까요?

샘플 5개를 batch_size=2로 나눠 봅시다.

drop_last=False → [0,1] [2,3] [4]  → 3배치
drop_last=True  → [0,1] [2,3]      → 2배치

숫자는 샘플 번호입니다. False면 작은 마지막 배치를 남기고, True면 정한 크기보다 작은 마지막 배치만 버립니다. 정확히 나누어떨어지면 마지막 배치도 그대로 사용합니다.

직접 묶어 보기 · 샘플은 5개

묶음: [[0,1],[2,3],[4]]

배치 수: 3

샘플 번호를 묶는 브라우저 그림입니다. 실제 PyTorch를 실행하지 않습니다.

batch_size=6·drop_last=True이면 5개짜리 불완전한 배치를 버려 배치가 0개가 됩니다. 수업에서 next를 했는데 아무것도 못 꺼내는 이유가 될 수 있습니다.

PyTorch DataLoader 자체의 기본 drop_last는 False입니다. 교안의 create_dataloader_v1 함수는 기본값을 True로 정했으므로 실제 호출값도 확인하세요.

5. 왜 한 번에 묶을까요? epoch와는?

여러 샘플을 텐서로 쌓으면 모델이 한꺼번에 배열 연산을 할 수 있습니다. 전체 데이터를 한 번에 넣는 대신 배치로 나누면 한 번의 계산에 필요한 메모리도 조절할 수 있습니다. 배치가 무조건 클수록 더 빠르거나 성능이 좋은 것은 아닙니다.

Epoch(에포크)는 보통 전체 학습 데이터를 한 차례 도는 단위입니다. 샘플 10개·batch_size=2면 한 번 순회하는 데 5배치를 꺼냅니다. 일반적인 ‘배치마다 한 번 파라미터 갱신’ 학습 루프에서는 그동안 5번 갱신합니다. gradient accumulation 같은 다른 학습 루프는 갱신 횟수가 달라질 수 있습니다.

drop_last=True이면 마지막 일부 샘플은 해당 순회에서 쓰지 않을 수 있습니다. shuffle=True는 샘플 순서를 섞지만 각 입력·정답의 짝은 유지합니다.

6. 눈으로 보고 출력으로 확인하기

import torch
from torch.utils.data import TensorDataset, DataLoader

# 샘플 5개, 한 입력의 길이 4
x = torch.tensor([
    [10,20,30,40],
    [20,30,40,50],
    [30,40,50,60],
    [40,50,60,70],
    [50,60,70,80],
])
y = torch.tensor([
    [20,30,40,50],
    [30,40,50,60],
    [40,50,60,70],
    [50,60,70,80],
    [60,70,80,90],
])

dataset = TensorDataset(x, y)
loader = DataLoader(dataset, batch_size=2, shuffle=False, drop_last=False)

print("샘플 수:", len(dataset))  # 5
print("배치 수:", len(loader))   # 3
for inputs, targets in loader:
    print(inputs.shape, targets.shape)

assert [tuple(inputs.shape) for inputs, targets in loader] == [
    (2,4), (2,4), (1,4)
]

TensorDataset은 이미 만든 x·y 텐서의 같은 행을 샘플 한 쌍으로 제공합니다. 교안 GPTDatasetV1은 원문을 잘라 샘플을 만드는 다른 방식이며, 여기서는 배치만 집중해서 보려고 TensorDataset을 사용했습니다.

참고: PyTorch DataLoader 공식 설명. 사용자 제공 도움말의 batch_size·drop_last·자동 배치 구성을 예시로 풀었습니다.

한 문장씩 기억하기

  • 샘플: 학습 예제 하나. 지금 교안에서는 입력·정답 쌍.
  • 배치: 한 번에 꺼내는 샘플 묶음.
  • batch_size: 묶음에 담을 샘플 수.
  • epoch: 학습 데이터를 한 차례 순회하는 단위.

이해 확인 · 설명을 가리고 풀기

1~5번은 자동 확인, 6번은 설명 비교, 7번은 직접 실습입니다. 답을 저장·전송하지 않습니다.
