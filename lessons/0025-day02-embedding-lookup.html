Embedding은 토큰 ID마다 학습할 벡터를 하나씩 가진 표입니다.
이번 코드는 그 표에서 입력 ID에 해당하는 행을 조회합니다.

6·4·3 구분행을 꺼내는 그림왜 이 표가 필요할까?코드 확인이해 확인

네, 사용할 수 있는 ID는 0~5이고 이번 입력에는 ID가 4개 들어 있습니다. 꼭 6종류를 모두 입력할 필요는 없습니다. 같은 ID를 여러 번 넣어도 됩니다.

input_ids = [2, 3, 5, 1]     # shape (4,): ID 네 개
weight                      # shape (6,3): 6개 ID의 벡터 표
embedding_layer(input_ids)  # shape (4,3): ID 네 개 각각에 실수 세 개

여기서 4는 입력 원소 개수입니다. 지금 입력은 1차원이라 별도의 배치 축은 없습니다. 앞에서 본 (배치 수, 토큰 길이) 형태와 구분하세요.

2. 입력 숫자를 누르면 어느 행을 가져오는지 보입니다

이번 입력 — 숫자를 눌러 선택하세요:

입력 위치 0의 값 2 → weight[2] 행을 꺼내 출력 0번째 행에 놓습니다.

① weight 표 (6,3)

행 번호가 토큰 ID입니다. 0부터 셉니다.

② 꺼낸 결과 (4, 3)

입력에 적은 순서대로 행을 모읍니다.

출력 위치어디서?값 1값 2값 3

위 숫자는 제공한 코드 그대로 Python 3.12.8·PyTorch 2.5.1에서 실행한 표를 소수 넷째 자리로 반올림한 값입니다. 브라우저는 이 고정 표를 조회하며 새로 학습하거나 PyTorch를 실행하지 않습니다. 다른 실행 환경·난수 상태에서는 초기값이 달라질 수 있습니다.

첫 입력은 2이므로 표의 ‘2번 행’을 가져옵니다.

0번부터 세면 세 번째 행이지만 ID는 2입니다. 표의 두 번째 열을 고르는 것도, ID 2에 weight를 곱하는 것도 아닙니다.

input_ids: [2,       3,       5,       1]
             ↓        ↓        ↓        ↓
표에서:   weight[2] weight[3] weight[5] weight[1]
             ↓        ↓        ↓        ↓
출력:    [1.2753, -0.2010, -0.1606]  # ID 2
         [-0.4015, 0.9666, -1.1481]  # ID 3
         [-2.8400,-0.7849, -1.4096]  # ID 5
         [0.9178, 1.5810,  1.3010]  # ID 1

입력을 [1,1,0]으로 바꿔 보세요. 1번 행이 두 번 나오고 출력 shape는 (3,3)이 됩니다. 0~5까지 있는 표 자체의 크기 (6,3)는 변하지 않습니다.

3. “그냥 중간 weight 때문에 만든 레이어”는 아닙니다

임베딩은 ‘ID라는 이름표’를 ‘모델이 사용할 학습 가능한 벡터’에 연결하는 역할을 합니다. token ID 2와 3이 가깝다고 두 토큰의 뜻이 비슷하다는 의미는 아닙니다. ID는 식별 번호이고, 모델은 해당 ID의 벡터를 학습해 사용할 수 있습니다.

예를 들어 ID 2를 “차”, ID 3을 “커피”라고 부르는 작은 어휘를 가정하면 각각 자기 벡터를 가집니다. 적절한 학습을 거쳐 관련된 특성을 표현할 수 있지만, 지금 처음 만든 무작위 벡터에 이미 그런 의미가 들어 있는 것은 아닙니다. 세 좌표에 사람이 ‘맛·온도·가격’을 정해 놓은 것도 아닙니다.

embedding_layer.weight가 바로 이 학습 가능한 표입니다. 여기서는 6×3=18개의 실수 파라미터가 있습니다. embedding_layer(input_ids) 호출은 표를 조회할 뿐이며, 혼자서 weight를 학습하거나 바꾸지 않습니다. 이후 손실·역전파·optimizer 갱신을 통해 학습합니다. 정수 ID 자체는 바꾸어 학습하지 않습니다.

torch.manual_seed(123)은 초기 무작위 값을 같은 조건에서 재현하도록 돕는 설정입니다. 표에 의미를 학습시키는 명령은 아닙니다.

4. 코드에서 직접 같은 행인지 확인

import torch
input_ids = torch.tensor([2,3,5,1])
vocab_size = 6
output_dim = 3

torch.manual_seed(123)
embedding_layer = torch.nn.Embedding(vocab_size, output_dim)
token_embeddings = embedding_layer(input_ids)

print(embedding_layer.weight.shape)  # (6,3)
print(input_ids.shape)               # (4,)
print(token_embeddings.shape)        # (4,3)

# 첫 출력은 ID 2의 행입니다.
assert torch.equal(token_embeddings[0], embedding_layer.weight[2])

# 기본 Embedding의 이 조회는 표를 직접 인덱싱한 결과와 같습니다.
assert torch.equal(token_embeddings, embedding_layer.weight[input_ids])

# 정수 ID는 그대로이며, 출력 벡터가 추가로 만들어집니다.
assert input_ids.tolist() == [2,3,5,1]

벡터 숫자를 외우지 말고 “입력 ID로 표의 행을 조회한다”를 설명할 수 있으면 됩니다. ID 6을 넣으면 0~5 범위를 벗어나 오류가 납니다.
