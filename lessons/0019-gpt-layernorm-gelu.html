1. 세 모듈의 역할

모듈역할작은 예
LayerNorm(층 정규화)한 토큰 벡터의 마지막 축을 정규화[1,3] → 대략 [-1,1]
GELUGaussian Error Linear Unit, 비선형 활성화0은 0, 작은 음수는 일부 남길 수 있음
FeedForward(순방향 네트워크)각 토큰을 개별적으로 가공8차원 → 32차원 → 8차원

2. LayerNorm 빈칸 네 곳

mean = x.mean(dim=-1, keepdim=True)
var = x.var(dim=-1, keepdim=True, unbiased=False)
norm_x = (x - mean) / torch.sqrt(var + self.eps)
return self.scale * norm_x + self.shift

답은 mean, var, scale, shift입니다. keepdim=True는 평균·분산의 축을 남겨 원래 벡터와 계산할 수 있게 합니다. unbiased=False로 이 벡터 자체의 분산을 계산합니다. eps=1e-5는 0으로 나누는 상황을 완화합니다.

숫자 예: [1,3]의 평균은 2, 분산은 1입니다. 평균을 빼면 [-1,1], sqrt(1+eps)로 나누면 거의 [-1,1]입니다. 초기 scale=1·shift=0이고 이후 학습할 수 있으므로 최종 출력이 언제나 평균 0·분산 1로 고정되는 것은 아닙니다. 배치나 토큰끼리 평균내는 코드가 아닙니다.

3. GELU와 FeedForward의 세 빈칸

self.layers = nn.Sequential(
    nn.Linear(cfg["emb_dim"], 4 * cfg["emb_dim"]),
    GELU(),
    nn.Linear(4 * cfg["emb_dim"], cfg["emb_dim"]),
)

답은 4, GELU, 4입니다. GELU가 비선형성을 추가하므로 두 Linear만 합친 것과 다른 표현을 배울 수 있습니다. 이 교안 GELU는 tanh를 이용한 근사식이며 ReLU처럼 모든 음수를 0으로 만들지는 않습니다.

입력(B,T,8)
→
Linear 확장(B,T,32)
→
GELU(B,T,32)
→
Linear 축소(B,T,8)

FeedForward는 각 토큰에 같은 네트워크를 적용합니다. 토큰 사이의 정보를 섞는 역할은 앞의 Attention이 맡습니다. nn.Sequential은 순서대로 모듈을 통과시킵니다.

시도 후 셀 3 전체 완성 코드 보기
class LayerNorm(nn.Module):
    """
    층 정규화 (Layer Normalization): 학습 안정성을 높임
    """
    def __init__(self, emb_dim):
        super().__init__()
        self.eps = 1e-5
        self.scale = nn.Parameter(torch.ones(emb_dim)) # 학습 가능한 스케일 파라미터 (Gamma)
        self.shift = nn.Parameter(torch.zeros(emb_dim)) # 학습 가능한 시프트 파라미터 (Beta)

    def forward(self, x):
        mean = x.mean(dim=-1, keepdim=True)
        var = x.var(dim=-1, keepdim=True, unbiased=False)
        norm_x = (x - mean) / torch.sqrt(var + self.eps)
        return self.scale * norm_x + self.shift

class GELU(nn.Module):
    """
    GELU 활성화 함수: GPT 계열에서 주로 사용하는 비선형 함수
    """
    def __init__(self):
        super().__init__()

    def forward(self, x):
        return 0.5 * x * (1 + torch.tanh(
            torch.sqrt(torch.tensor(2.0 / torch.pi)) *
            (x + 0.044715 * torch.pow(x, 3))
        ))

class FeedForward(nn.Module):
    """
    피드 포워드 네트워크 (Feed-Forward Network)
    어텐션이 모은 정보를 각 토큰별로 개별적으로 가공하는 역할
    보통 임베딩 차원을 4배로 늘렸다가 다시 줄임
    """
    def __init__(self, cfg):
        super().__init__()
        self.layers = nn.Sequential(
            nn.Linear(cfg["emb_dim"], 4 * cfg["emb_dim"]),
            GELU(),
            nn.Linear(4 * cfg["emb_dim"], cfg["emb_dim"]),
        )

    def forward(self, x):
        return self.layers(x)
