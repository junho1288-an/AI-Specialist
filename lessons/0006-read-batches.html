배치를 하나씩 꺼내기

교안 코드를 이해하고, 설명을 닫은 뒤 빈 노트북에 직접 작성합니다.

교안 기반 자체 연습입니다. 실제 출제 여부는 강사 공지를 따릅니다.

전체 목차이전 수업시험 문제복습 카드

1. iter는 읽을 위치, next는 다음 묶음

DataLoader배치들을 제공
→
iter(dataloader)순회할 iterator 만들기
→
next(data_iter)다음 배치 하나 꺼내기

Iterator(이터레이터)는 어디까지 읽었는지 기억하는 객체입니다. 같은 data_iter에 next를 호출할 때마다 다음 배치로 이동합니다.

예시: 도서관 대출 카드 묶음을 읽는다고 생각하세요. iter는 첫 묶음부터 읽을 준비, 첫 next는 첫 묶음, 두 번째 next는 두 번째 묶음입니다.

2. 교안 코드와 저장된 출력

# 앞 셀의 raw_text, GPTDatasetV1, create_dataloader_v1이 필요합니다.
dataloader = create_dataloader_v1(
    raw_text, batch_size=1, max_length=4, stride=1, shuffle=False
)

data_iter = iter(dataloader)
first_batch = next(data_iter)
print(first_batch)

second_batch = next(data_iter)
print(second_batch)
첫 배치 입력: [[40, 367, 2885, 1464]]
첫 배치 정답: [[367, 2885, 1464, 1807]]

둘째 배치 입력: [[367, 2885, 1464, 1807]]
둘째 배치 정답: [[2885, 1464, 1807, 3619]]

숫자는 원본 노트북에 저장된 출력입니다. 여기서 새로 원문을 다운로드해 실행한 결과는 아닙니다.

설정현재 결과에 미치는 영향
batch_size=1한 배치에 샘플 1개. 입력·정답 각각 shape (1,4).
max_length=4한 샘플 안에 토큰 4개.
stride=1다음 샘플 시작점은 한 칸 이동.
shuffle=False샘플 순서대로 꺼내므로 이동 관계가 보임.
stride=1이고 순서가 유지되므로 첫 정답 내용과 두 번째 입력 내용이 같아집니다. 모든 stride·shuffle 설정에서 성립하는 규칙은 아닙니다.

대괄호가 두 겹인 [[...]]는 배치 축과 토큰 축이 있기 때문입니다. 첫 배치 자체에는 입력 텐서·정답 텐서 두 항목이 있으며, 아래처럼 나눠 받을 수 있습니다.

inputs, targets = first_batch
print(inputs.shape, targets.shape)  # 각각 (1, 4)

3. next를 다시 쓰는 법

next(data_iter)와 next(iter(dataloader))는 다릅니다. 후자는 호출할 때마다 새 이터레이터를 만듭니다. shuffle=False이면 매번 첫 배치를 다시 꺼냅니다.

모든 배치를 읽은 뒤 next를 호출하면 StopIteration이 발생합니다. 새로 순회하려면 data_iter = iter(dataloader)를 다시 실행합니다. shuffle=True에서는 새 순회의 샘플 순서가 바뀔 수 있습니다.

손으로 순서 확인하기
batches = iter(["첫 배치", "둘째 배치"])
print(next(batches))  # 첫 배치
print(next(batches))  # 둘째 배치
print(next(batches, "끝"))  # 끝

마지막 줄은 기본값을 줘서 예외 대신 "끝"을 돌려받는 예입니다. 교안의 next(data_iter)는 기본값이 없어 소진 시 예외가 납니다.

교안: 다섯 번째 코드 셀 · iter와 next. API 근거: Python iter·next 공식 설명.

설명을 가리고 풀어 보기

1~5번 자동 확인, 6번 설명 비교, 7번 직접 코딩. 브라우저에서는 Python을 실행하지 않으며 답변을 저장·전송하지 않습니다.

01 · 순회 객체 만들기

data_iter = ????(dataloader)

시도 후 정답·해설

iter. 예: iter(dataloader)는 배치를 순회할 이터레이터를 만듭니다.

02 · 다음 배치 꺼내기

first_batch = ????(data_iter)

시도 후 정답·해설

next. 예: 같은 data_iter에 next를 두 번 쓰면 첫 배치, 둘째 배치가 나옵니다.

03 · 두 겹 대괄호

batch_size=1, max_length=4라면 입력 shape의 첫 축 크기는?

시도 후 정답·해설

1. 입력 shape는 (1,4)입니다. 샘플 1개 안에 토큰 4개가 있습니다.

04 · 매번 새로 iter를 만들면?

“shuffle=False에서 next(iter(dataloader))를 두 번 실행하면 첫 배치와 둘째 배치가 차례로 나온다.”

시도 후 정답·해설

X. 매번 새 이터레이터를 만들므로 첫 배치를 두 번 꺼냅니다.

05 · 배치를 다 읽었다면?

소진된 이터레이터에 기본값 없이 next를 쓰면 발생하는 예외 이름은?

시도 후 정답·해설

StopIteration. 예: 배치가 2개인 이터레이터에 세 번째 next를 쓰면 StopIteration입니다.

06 · 내 말로 설명하기

첫 배치 정답과 두 번째 배치 입력이 같은 이유를 설정 두 가지와 연결해 설명하세요.

작성 후 비교할 해설

예: stride=1로 한 칸씩 이동하고 shuffle=False로 순서대로 조회하기 때문입니다. 정답 자체도 입력보다 한 칸 뒤입니다. stride=2나 섞인 순서에서는 같다고 보장할 수 없습니다.

07 · 빈 노트북 실기

제출 위치: practice/day-01/read-batches.ipynb. 폴더와 파일은 직접 만드세요. 예상 5분, PyTorch가 설치된 환경에서 진행합니다.

입력 텐서 [[10,20],[20,30],[30,40]], 정답 텐서 [[20,30],[30,40],[40,50]]를 TensorDataset으로 묶으세요. batch_size=1, shuffle=False로 첫·둘째 배치를 꺼내 첫 정답과 둘째 입력이 같은지 검사하세요.

시도 후 모범 코드
import torch
from torch.utils.data import TensorDataset, DataLoader

x = torch.tensor([[10,20],[20,30],[30,40]])
y = torch.tensor([[20,30],[30,40],[40,50]])
loader = DataLoader(TensorDataset(x, y), batch_size=1, shuffle=False)
data_iter = iter(loader)
first_x, first_y = next(data_iter)
second_x, second_y = next(data_iter)
print(first_x, first_y, second_x, second_y)
assert tuple(first_x.shape) == (1, 2)
assert torch.equal(first_y, second_x)

원문이나 토크나이저 없이 배치 조회 순서를 확인하는 연습입니다.
