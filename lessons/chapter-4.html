작은 부품에서 GPT 생성까지

데이터 → Attention → 정규화·FF → GPT 조립 → 한 토큰씩 생성.

내용이 있는 코드 셀 6개는 각각 설명·그림·예시·전체 완성 코드·연습 7개를 제공합니다. 마지막 셀은 원래 비어 있어 선택 복습으로 안내합니다.

셀수업목표
1셀 1 · GPT용 데이터 준비 복습문자열 → 입력·정답 쌍 → 배치 흐름 다시 연결

4셀 4 · TransformerBlock과 GPTModel 조립토큰 ID에서 어휘별 logits까지 전체 shape 연결

무작위 초기화와 사전학습 구분

이 코드의 GPTModel(config)는 학습된 GPT-2 가중치를 로드하지 않습니다. 토큰 생성 루프가 동작해도 출력 문장이 자연스러울 필요는 없습니다. config 이름의 124M이 실제 파라미터 수를 자동 보장하지도 않습니다.

실행 코드의 빈칸은 셀 3에 7곳, 셀 4에 8곳, 셀 5에 4곳으로 총 19곳입니다. 원본 노트북은 보존하고, 연습용 노트북에서 앞 셀 정의부터 순서대로 실행하세요.

첫 실행 확인은 큰 설정 대신 vocab_size=32·emb_dim=8·블록 2개의 작은 모델로 합니다. 이때 실제 GPT-2 ID를 넣으면 어휘 범위를 벗어날 수 있으므로 0~31의 연습용 ID를 사용합니다.
