셀 5 · 다음 토큰을 하나씩 붙이기

문맥 자르기 → 마지막 logits → argmax → cat 반복

셀 번호는 파일 위에서부터 센 순서입니다. 자체 연습 문제이며 실제 출제 범위는 강사 공지를 따릅니다.

Chapter 4 목차이전확인 문제복습 카드

1. 생성은 새 토큰을 다시 입력에 붙이는 반복

현재 ID(B,T)
→
마지막 문맥 + model(B,T_cond,V)
→
마지막 위치 + argmax(B,1)
→
cat(dim=1)(B,T+1)

예시: 문맥 [1,2]에서 3을 고르면 [1,2,3], 다음 4를 고르면 [1,2,3,4]가 됩니다. 이 숫자 순서는 이해용 예시이며 실제 모델의 예측 규칙이 아닙니다.

2. 네 빈칸 정답

idx_cond = idx[:, -context_size:]
with torch.no_grad():
    logits = model(idx_cond)
logits = logits[:, -1, :]
idx_next = torch.argmax(logits, dim=-1, keepdim=True)
idx = torch.cat((idx, idx_next), dim=1)

답은 no_grad, -1, argmax, cat입니다. 마지막 위치의 출력이 지금 문맥 뒤의 토큰을 예측합니다. keepdim=True는 결과를 (B,1)로 남겨 idx의 시간 축에 이어 붙일 수 있게 합니다.

Greedy decoding(탐욕적 선택)은 매번 현재 점수가 가장 높은 ID를 고릅니다. softmax는 점수 순서를 유지하므로 argmax 전에 꼭 적용할 필요가 없습니다. 최종 문장 전체가 가장 좋은 결과라고 보장하는 선택은 아닙니다.

전체 기록과 모델에 넣는 문맥 구분

전체 idx: [1,2]

context_size=3일 때 idx_cond: [1,2]

이 단계에 붙인다고 가정한 ID: 3

고정된 숫자를 붙이는 시각화이며 실제 GPT를 실행하지 않습니다. 슬라이더는 현재 단계에서 선택 직전의 상태를 보여줍니다.

eval과 no_grad는 역할이 다릅니다.

model.eval()은 dropout 같은 모듈의 동작을 평가 모드로 바꾸고, torch.no_grad()는 해당 계산의 기울기 기록을 끕니다. 이 함수는 eval을 호출하지 않으므로 실행하는 쪽에서 설정합니다.

context_size는 양수이고 모델의 context_length 이하여야 합니다. 잘라내는 것은 모델에 넣을 idx_cond이며 전체 idx 기록은 남깁니다. 이 교안 함수는 EOS 조기 종료 없이 max_new_tokens번 반복합니다. 새로 생성한 토큰 수와 글자 수는 다릅니다.

시도 후 셀 5 전체 완성 코드 보기
def generate_text_simple(model, idx, max_new_tokens, context_size):
    """
    간단한 텍스트 생성 루프
    현재 문맥을 넣어 다음 토큰을 예측하고, 이를 다시 문맥에 추가하여 반복함
    """
    for _ in range(max_new_tokens):

        idx_cond = idx[:, -context_size:]

        with torch.no_grad():
            logits = model(idx_cond)

        logits = logits[:, -1, :]

        idx_next = torch.argmax(logits, dim=-1, keepdim=True)

        idx = torch.cat((idx, idx_next), dim=1)

    return idx

원본 실행 코드에 정답을 채우고 주석을 줄였습니다. 이전 셀 정의에 의존하므로 위에서 아래로 실행하세요. 원본 노트북은 변경하지 않았습니다.

기억해서 풀어 보기

1~5번 자동 확인, 6번 설명 비교, 7번 직접 코딩입니다. 브라우저는 Python을 실행하지 않고 답을 저장·전송하지 않습니다.

01 · 기울기 없이 예측

with torch.????():

시도 후 정답·해설

no_grad. 예측 단계의 역전파용 계산 기록을 끕니다. eval과 다릅니다.

02 · 마지막 위치

logits = logits[:, ????, :]

시도 후 정답·해설

-1. 마지막 입력 위치의 점수가 그다음 토큰을 예측합니다.

03 · 가장 큰 점수 선택

idx_next = torch.????(logits, dim=-1, keepdim=True)

시도 후 정답·해설

argmax. 가장 큰 값 자체가 아니라 그 값의 위치인 토큰 ID를 선택합니다.

04 · 뒤에 이어 붙이기

idx = torch.????((idx, idx_next), dim=1)

시도 후 정답·해설

cat. 예: (1,4)와 (1,1)을 시간 축에 연결해 (1,5)를 만듭니다.

05 · eval의 역할

“model.eval()을 호출하면 자동으로 모든 기울기 기록이 꺼진다.”

시도 후 정답·해설

X. eval은 모듈의 평가 모드이며 no_grad는 기울기 기록 제어입니다.

06 · 내 말로 설명

왜 logits 전체가 아닌 마지막 위치를 쓰며, 왜 keepdim=True가 필요한가요?

작성 후 비교할 해설

지금 문맥 뒤의 다음 토큰은 마지막 위치의 logits로 고릅니다. 예: (B,V)의 argmax를 (B,1)로 유지해야 (B,T)에 같은 축 수로 이어 붙일 수 있습니다.
