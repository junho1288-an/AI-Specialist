글자가 숫자로 바뀌는 순간

BPE → 토큰 ID → 원래 문자열.
오늘은 encode와 decode 두 줄을 혼자 쓰고 설명합니다.

기준: Chapter_2_Exercise_Dataset.ipynb 첫 코드 셀. 시험 형식을 연습하는 자체 문제이며 실제 출제 확정 문제는 아닙니다.

흐름 그림BPE교안 코드시험 문제복습 카드

1. 토크나이저는 ‘조각과 번호’를 다룹니다

토큰(token)은 텍스트를 처리하는 조각, 토크나이저(tokenizer)는 텍스트를 그 조각들의 ID로 바꾸는 도구입니다.

문자열"Hello,"
→
encode조각을 나누고 ID 찾기
→
ID 리스트[15496, 11]

같은 토크나이저의 decode로 돌아오면 → "Hello,"

HelloID 15496
,ID 11

숫자는 어휘표에 정해진 식별 번호예요. 전화번호부에서 이름에 대응하는 번호를 찾듯, 토큰에 대응하는 ID를 찾습니다. 15496는 글자 수·중요도·뜻의 점수가 아닙니다. 정수 하나의 타입은 int, 여러 ID를 담은 integers는 list[int]입니다.

이 ID와 아래 출력은 교안 노트북에 저장된 GPT-2 실행 결과를 기준으로 합니다. 인코딩 방식이 달라지면 같은 글자도 다른 ID가 될 수 있습니다. tiktoken 공식 예제

2. BPE는 자주 붙는 조각을 합칩니다

BPE = Byte Pair Encoding(바이트 페어 인코딩). 토크나이저를 학습할 때 자주 함께 등장하는 인접 조각 두 개를 합치는 규칙을 만듭니다.

작은 조각l | o | w
→
자주 붙으면 합치기lo | w
→
더 큰 조각low

위 그림은 해당 쌍이 자주 나온다고 가정한 학습용 예시이며 GPT-2의 실제 병합 순서를 뜻하지 않습니다. GPT-2는 UTF-8 바이트를 기본 단위로 하는 byte-level BPE를 사용합니다.

지금 코드에서는 BPE를 새로 학습하지 않습니다.
get_encoding("gpt2")로 이미 정해진 어휘표와 병합 규칙을 불러온 뒤, encode로 적용합니다. 자주 쓰는 조각을 묶을 수 있고 낯선 단어도 더 작은 조각으로 표현할 수 있습니다.

Hugging Face: BPE 학습과 적용의 차이

3. 교안 코드, 꼭 필요한 부분만

import importlib.metadata
import tiktoken

print("tiktoken version:", importlib.metadata.version("tiktoken"))
tokenizer = tiktoken.get_encoding("gpt2")

text = (
    "Hello, do you like tea? <|endoftext|> In the sunlit terraces"
    "of someunknownPlace."
)

integers = tokenizer.encode(text, allowed_special={"<|endoftext|>"})
print(integers)

strings = tokenizer.decode(integers)
print(strings)
assert strings == text
코드쉽게 말하면
importlib.metadata.version(...)설치한 패키지 버전 확인. 토큰화 자체를 하는 줄은 아닙니다. 하위 모듈을 명시적으로 import했습니다.
get_encoding("gpt2")GPT-2의 인코딩 규칙 선택. 인자는 정확히는 인코딩 이름입니다. GPT 모델의 가중치를 불러오는 동작은 아닙니다.
encode(text, ...)문자열 → 토큰 ID 리스트.
allowed_special={...}원문 속 종료 표시를 하나의 특수 토큰으로 인식하도록 허용.
decode(integers)같은 규칙으로 ID 리스트 → 문자열 복원.

공식 encode/decode API와 특수 토큰 처리

교안에 저장된 실제 출력 살펴보기
[15496, 11, 466, 345, 588, 8887, 30, 220, 50256,
 554, 262, 4252, 18250, 8812, 2114, 1659, 617,
 34680, 27271, 13]

15496는 Hello, 11은 쉼표, 50256은 이 인코딩의 <|endoftext|>입니다. 문장 전체가 20개 토큰으로 표현됩니다. 단어 하나가 언제나 토큰 하나인 것은 아닙니다.

출처는 원본 노트북의 저장된 출력입니다. 이 HTML이 실시간으로 Python을 실행한 결과는 아닙니다.

원문을 그대로 복원한다는 뜻
교안의 두 문자열 사이에는 자동으로 공백이 생기지 않아 terracesof가 됩니다. decode는 이를 terraces of로 교정하지 않습니다. 띄어쓰기를 원하면 원본 문자열에 공백을 넣어야 합니다.

<|endoftext|>는 종료 표시에 쓰는 특수 토큰이지만, 여기서는 그 뒤에 텍스트가 있어도 함께 인코딩됩니다. 이 옵션은 인코딩을 중단시키라는 명령이 아닙니다.

4. 이제 설명을 가리고 풀어 보세요

브라우저는 답만 확인하며 Python 코드를 실행하지 않습니다. 입력 내용은 서버로 전송하거나 학습 기록에 자동 저장하지 않습니다. 실제 코딩은 마지막 문제에서 합니다.

01 · 문자열을 숫자로

integers = tokenizer.????(text, allowed_special={"<|endoftext|>"})

시도 후 정답·해설

encode. 예: tokenizer.encode("Hello,") → [15496, 11].

02 · 숫자를 문자열로

strings = tokenizer.????(integers)

시도 후 정답·해설

decode. 예: tokenizer.decode([15496, 11]) → "Hello,".

03 · 숫자의 뜻

“ID가 15496인 토큰은 ID가 11인 토큰보다 중요하다.”

시도 후 정답·해설

X. ID는 식별 번호입니다. 예: Hello의 ID 15496과 쉼표의 ID 11은 중요도 점수가 아닙니다.

04 · BPE를 언제 학습할까?

“이 실습의 encode는 이미 정해진 BPE 규칙을 사용한다.”

시도 후 정답·해설

O. 이미 배운 규칙을 적용합니다. BPE 학습 예시는 l | o → lo처럼 자주 붙는 쌍을 합치는 것입니다.

05 · 디코딩 결과 예측

text = "terraces" "of"
restored = tokenizer.decode(tokenizer.encode(text))

시도 후 정답·해설

terracesof. 예: "a" "b"도 "ab"가 됩니다.

06 · 특수 토큰을 내 말로

allowed_special={"<|endoftext|>"}는 왜 넣을까요? 답을 한 문장으로 적으세요.

작성 후 비교할 해설

원문에 있는 <|endoftext|>를 특수 토큰으로 인식하도록 허용하기 위해서입니다. 예: 이 GPT-2 규칙에서는 ID 50256에 대응합니다. 이 문자열이 있는 상태에서 기본 설정으로 encode하면 오류가 날 수 있습니다.

07 · 빈 노트북 실기

이 페이지를 닫고 practice/day-01/tokenizer-roundtrip.ipynb에 작성하세요. 예상 5분. 폴더와 파일은 직접 만듭니다.

  1. tiktoken을 import하고 GPT-2 인코딩을 선택합니다.
  2. "Hello, <|endoftext|> tea?"를 인코딩하고 ID 리스트와 토큰 개수를 출력합니다.
  3. 디코딩해 출력하고 원문과 같은지 assert로 검사합니다.
  4. 숫자 ID가 뜻하는 것과 특수 토큰 옵션을 한 문장씩 설명합니다.
시도 후 모범 코드
import tiktoken
tokenizer = tiktoken.get_encoding("gpt2")
text = "Hello, <|endoftext|> tea?"
ids = tokenizer.encode(text, allowed_special={"<|endoftext|>"})
print(ids, len(ids))
restored = tokenizer.decode(ids)
print(restored)
assert restored == text

완료 기준: 새 커널에서 전체 실행 성공 + 원문 복원 + 두 문장 설명. 답안을 보았다면 도움받아 완료로 기록하고, 다음날 자료 없이 다시 작성합니다.

6번 메모는 초기화 대상이 아닙니다. 자동 확인 문제는 1~5번입니다. 답변이나 코드를 에이전트에게 보내면 오답 이유와 설명도 함께 확인합니다.
