원래 비어 있는 셀을 선택 복습·재작성 공간으로 활용

셀 번호는 파일 위에서부터 센 순서입니다. 자체 연습 문제이며 실제 출제 범위는 강사 공지를 따릅니다.

Chapter 4 목차이전확인 문제복습 카드

1. 이 셀에는 원래 코드가 없습니다

추가 교안 내용이나 ???? 정답은 없습니다. 아래는 빈 셀을 활용하는 선택 복습입니다.

2. 전체 흐름을 한 번에 설명하기

토큰 ID(B,T)
→
토큰 + 위치 임베딩(B,T,E)
→
여러 블록(B,T,E)
→
어휘별 logits(B,T,V)

예시: 작은 모델에서 B=1, T=3, E=8, V=32라면 logits는 (1,3,32), 마지막 위치는 (1,32), argmax를 keepdim=True로 구하면 (1,1)입니다. 이를 원래 ID에 붙이면 길이가 4가 됩니다.

3. 다음날 복습

  1. LayerNorm의 평균·분산·scale·shift를 사용하는 한 줄.
  2. 블록의 Attention·FeedForward와 residual 순서.
  3. 토큰 ID → logits → 마지막 위치 argmax → cat 생성 흐름.

실제 제출 코드로 설명과 실행 결과를 확인한 뒤 숙달 기록을 갱신합니다.
