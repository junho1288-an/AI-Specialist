샘플을 배치로 묶기

교안 코드를 이해하고, 설명을 닫은 뒤 빈 노트북에 직접 작성합니다.

전체 목차이전 수업시험 문제복습 카드

1. Dataset은 샘플, DataLoader는 묶음

텍스트txt
→
Dataset입력·정답 카드 여러 장
→
DataLoader카드를 batch_size개씩 묶기

배치(batch)는 한 번에 꺼내는 샘플 묶음입니다. create_dataloader_v1은 토크나이저 → Dataset → DataLoader를 차례로 준비해 반환하는 도우미 함수입니다.

예시: 샘플이 5개, batch_size=2라면 [0,1] [2,3] [4]로 나눌 수 있습니다. 이 번호는 샘플 번호이지 토큰 ID가 아닙니다.

2. 교안의 빈칸 정답은 dataset

import tiktoken
from torch.utils.data import DataLoader

# 앞 셀에서 GPTDatasetV1 클래스를 정의해 두어야 합니다.
def create_dataloader_v1(txt, batch_size=4, max_length=256,
                         stride=128, shuffle=True, drop_last=True,
                         num_workers=0):
    tokenizer = tiktoken.get_encoding("gpt2")
    dataset = GPTDatasetV1(txt, tokenizer, max_length, stride)
    dataloader = DataLoader(
        dataset,
        batch_size=batch_size,
        shuffle=shuffle,
        drop_last=drop_last,
        num_workers=num_workers
    )
    return dataloader

DataLoader 첫 번째 인자에는 실제 샘플을 제공할 dataset 객체를 넣습니다. 원문 문자열 txt나 클래스 이름 GPTDatasetV1 자체를 넣는 것이 아닙니다. 교안에서 앞서 import한 DataLoader를 여기서는 명시했습니다.

인자쉬운 뜻예시
batch_size한 배치에 묶을 샘플 수2 → 샘플 2개씩
max_length샘플 하나의 토큰 길이4 → 입력 토큰 4개
stride샘플 시작점 이동 간격2 → 시작점 0,2,4…
shuffle샘플을 꺼내는 순서를 섞을지False → 저장 순서 유지
drop_last마지막 작은 배치를 버릴지True → [4] 배치 제외
num_workers데이터를 불러올 작업 프로세스 수0 → 현재 프로세스에서 처리
shuffle은 샘플 순서를 섞습니다. 샘플 안 토큰을 섞거나 입력·정답 짝을 어긋나게 하는 옵션이 아닙니다. max_length와 stride는 Dataset에, 나머지 배치 옵션은 DataLoader에 전달합니다.

샘플 5개를 묶어 보기

배치: [[0,1],[2,3],[4]]

배치 수: 3

shuffle=False인 연습용 샘플 번호 그림입니다. PyTorch를 실행하지 않습니다.

현재 함수의 기본값은 drop_last=True입니다. 샘플 수가 batch_size보다 작으면 배치가 0개가 될 수 있습니다. 처음 결과를 확인할 때는 shuffle=False, drop_last=False를 명시하면 순서와 남은 샘플을 보기 쉽습니다.

함수를 정의하는 것만으로 데이터가 생성되지는 않습니다. 함수를 호출해야 실제 Dataset과 DataLoader가 만들어집니다.

01 · 어떤 객체를 넣을까?

dataloader = DataLoader(????, batch_size=batch_size)

시도 후 정답·해설

dataset. 예: DataLoader(dataset, batch_size=2)는 해당 데이터셋의 샘플을 2개씩 묶습니다.

02 · 샘플 수와 배치 수

샘플 5개, batch_size=2, drop_last=False이면 배치는 몇 개인가요?

시도 후 정답·해설

3. 예: [0,1], [2,3], [4]로 총 3개입니다.

03 · 작은 마지막 배치 제외

샘플 5개, batch_size=2, drop_last=True이면 배치는 몇 개인가요?

시도 후 정답·해설

2. 예: [4]는 2개보다 작아 버리고 [0,1], [2,3]만 반환합니다.

04 · 섞는 대상

“shuffle=True는 샘플 안의 토큰 순서를 무작위로 섞는다.”

시도 후 정답·해설

X. 예: 0번과 1번 샘플의 조회 순서는 바뀔 수 있어도 각 샘플의 입력·정답 내용은 그대로입니다.

05 · 현재 프로세스에서 읽기

DataLoader(dataset, num_workers=????)

현재 프로세스에서 데이터를 읽게 할 값은?

시도 후 정답·해설

0. num_workers=0은 별도 작업 프로세스를 만들지 않습니다.

06 · 내 말로 설명하기

batch_size=2와 max_length=4는 각각 무엇을 세나요?

작성 후 비교할 해설

예: 입력 배치 shape (2,4)는 샘플 2개, 샘플당 토큰 4개입니다. stride는 별도로 다음 샘플 시작점의 이동 간격입니다.

07 · 빈 노트북 실기

제출 위치: practice/day-01/batch-loader.ipynb. 폴더와 파일은 직접 만드세요. 예상 5분, PyTorch가 설치된 환경에서 진행합니다.

원문 다운로드 없이 연습합니다. torch.arange(10).reshape(5,2)로 샘플 5개를 만들고 TensorDataset으로 감싼 뒤, batch_size=2에서 drop_last를 False/True로 바꿔 배치 수와 첫 배치 shape를 확인하세요.

시도 후 모범 코드
import torch
from torch.utils.data import TensorDataset, DataLoader

samples = torch.arange(10).reshape(5, 2)
dataset = TensorDataset(samples)
for drop in [False, True]:
    loader = DataLoader(dataset, batch_size=2,
                        shuffle=False, drop_last=drop)
    print(drop, len(loader))
    assert len(loader) == (2 if drop else 3)
    first, = next(iter(loader))
    assert tuple(first.shape) == (2, 2)

TensorDataset에 텐서 하나를 넣어 배치에도 항목 하나만 있습니다. 이 과제는 배치 옵션을 확인하며, 교안의 GPTDatasetV1 입력·정답 두 항목 구조와 구분합니다.
