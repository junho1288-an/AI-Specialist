토큰 ID에서 어휘별 logits까지 전체 shape 연결

셀 번호는 파일 위에서부터 센 순서입니다. 자체 연습 문제이며 실제 출제 범위는 강사 공지를 따릅니다.

Chapter 4 목차이전확인 문제복습 카드

1. 블록은 ‘새 정보 + 원래 정보’

입력 x(B,T,E)
→
Norm → Attention가공한 정보
→
+ shortcut원래 입력 더하기
→
Norm → FF → +shortcut(B,T,E) 유지

Residual connection(잔차 연결)은 가공된 출력에 원래 입력을 더하는 경로입니다. 학습과 기울기 흐름을 돕습니다. 예를 들어 원래 [1,2]에 새 정보 [0.1,0.2]를 더하면 [1.1,2.2]입니다. 결과를 강제로 원본과 같게 만드는 것은 아닙니다.

빈칸 self.????(x) 두 곳은 순서대로 att, ff입니다. 이 교안은 정규화 후 모듈을 통과시키는 Pre-LayerNorm 구조입니다. 두 번째 shortcut은 Attention 잔차를 더한 뒤의 x를 새로 저장합니다.

2. GPT 전체의 shape 흐름

# 설명용 어휘 V=32, 길이 T=3, 배치 B=2, 임베딩 E=8
in_idx             # (2,3), 정수 토큰 ID
tok_embeds         # (2,3,8)
pos_embeds         # (3,8)
x = tok_embeds + pos_embeds  # (2,3,8)
x = self.trf_blocks(x)      # (2,3,8)
x = self.final_norm(x)      # (2,3,8)
logits = self.out_head(x)   # (2,3,32)
빈칸답이유
tok_emb cfg 키vocab_size토큰 ID 종류 수
pos_emb cfg 키context_length위치 표의 행 수
out_head cfg 키vocab_size각 어휘 ID의 점수 출력
tok_embeds와 더할 것pos_embeds위치 정보 반영
쌓은 블록 호출trf_blocksn_layers개 블록 통과
최종 점수 레이어out_head임베딩 차원을 어휘 차원으로

앞의 att·ff를 포함해 이 셀의 빈칸은 8곳입니다. *[TransformerBlock(...) ...]의 *는 모듈 목록을 nn.Sequential의 개별 인자로 펼칩니다.

logits는 아직 확률이 아닙니다.

예: 어휘 32개면 각 위치에서 점수 32개를 냅니다. 음수도 가능하고 합이 1일 필요도 없습니다. softmax하면 어휘별 분포가 되고 argmax하면 가장 높은 점수의 ID를 고를 수 있습니다.

토큰·위치 임베딩과 출력 헤드는 초기화된 학습 가능한 레이어입니다. 이 코드에서 tok_emb와 out_head 가중치는 별개이며 자동 공유되지 않습니다. 입력 토큰 ID는 vocab_size보다 작고, 입력 길이는 context_length 이하여야 합니다.

시도 후 셀 4 전체 완성 코드 보기
class TransformerBlock(nn.Module):
    """
    표준 트랜스포머 블록 (Decoder Block)
    구조: LayerNorm -> Attention -> Add(Residual) -> LayerNorm -> FeedForward -> Add(Residual)
    """
    def __init__(self, cfg):
        super().__init__()
        self.att = MultiHeadAttention(
            d_in=cfg["emb_dim"],
            d_out=cfg["emb_dim"],
            context_length=cfg["context_length"],
            num_heads=cfg["n_heads"],
            dropout=cfg["drop_rate"],
            qkv_bias=cfg["qkv_bias"])
        self.ff = FeedForward(cfg)
        self.norm1 = LayerNorm(cfg["emb_dim"])
        self.norm2 = LayerNorm(cfg["emb_dim"])
        self.drop_shortcut = nn.Dropout(cfg["drop_rate"])

    def forward(self, x):
        shortcut = x
        x = self.norm1(x) # Pre-LayerNorm 방식
        x = self.att(x)
        x = self.drop_shortcut(x)
        x = x + shortcut  # 원본 입력을 더해줌 (기울기 소실 방지)

        shortcut = x
        x = self.norm2(x)
        x = self.ff(x)
        x = self.drop_shortcut(x)
        x = x + shortcut  # 원본 입력 다시 더함

        return x
class GPTModel(nn.Module):
    """
    전체 GPT 모델 구조 정의
    Embedding -> Transformer Blocks -> Final Norm -> Output Head
    """
    def __init__(self, cfg):
        super().__init__()
        self.tok_emb = nn.Embedding(cfg["vocab_size"], cfg["emb_dim"])
        self.pos_emb = nn.Embedding(cfg["context_length"], cfg["emb_dim"])
        self.drop_emb = nn.Dropout(cfg["drop_rate"])

        self.trf_blocks = nn.Sequential(
            *[TransformerBlock(cfg) for _ in range(cfg["n_layers"])])

        self.final_norm = LayerNorm(cfg["emb_dim"])
        self.out_head = nn.Linear(cfg["emb_dim"], cfg["vocab_size"], bias=False)

    def forward(self, in_idx):
        batch_size, seq_len = in_idx.shape

        tok_embeds = self.tok_emb(in_idx)
        pos_embeds = self.pos_emb(torch.arange(seq_len, device=in_idx.device))

        x = tok_embeds + pos_embeds

        x = self.drop_emb(x)

        x = self.trf_blocks(x)

        x = self.final_norm(x)
        logits = self.out_head(x) # 각 단어에 대한 예측 점수 (Logits)

        return logits
