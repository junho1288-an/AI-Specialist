전체 목차이전 수업시험 문제복습 카드

1. 무엇인지와 어디인지를 함께

토큰 임베딩ID가 가리키는 벡터
(8,4,256)
→
위치 임베딩위치 0·1·2·3의 벡터
(4,256)
→
둘을 더한 입력모든 배치에 위치 정보 반영
(8,4,256)

같은 ID는 토큰 임베딩에서 같은 행을 꺼냅니다. 그래서 이 셀에서는 위치에 대응하는 별도의 학습 가능한 벡터를 더합니다. 단순한 위치 숫자 0·1·2·3 자체를 256차원 토큰 벡터에 더하는 것이 아닙니다.

작은 예시: 같은 토큰 벡터가 [1,2,3]이어도 위치 0의 벡터 [0.1,0.2,0.3]을 더하면 [1.1,2.2,3.3], 위치 1의 벡터 [0.4,0.5,0.6]을 더하면 [1.4,2.5,3.6]입니다. 이 값은 원리를 위한 설명용이며 실제 초기값이 아닙니다.

2. 교안의 전체 흐름

# 앞 셀에서 torch, raw_text, create_dataloader_v1이 필요합니다.
vocab_size = 50257
output_dim = 256
token_embedding_layer = torch.nn.Embedding(vocab_size, output_dim)

max_length = 4
dataloader = create_dataloader_v1(
    raw_text, batch_size=8, max_length=max_length,
    stride=max_length, shuffle=False
)
data_iter = iter(dataloader)
inputs, targets = next(data_iter)

token_embeddings = token_embedding_layer(inputs)
print(token_embeddings.shape)

context_length = max_length
pos_embedding_layer = torch.nn.Embedding(context_length, output_dim)
pos_embeddings = pos_embedding_layer(torch.arange(max_length))
print(pos_embeddings.shape)

input_embeddings = token_embeddings + pos_embeddings
print(input_embeddings.shape)
변수shape 또는 값읽는 법
inputs, targets(8,4)샘플 8개 × 토큰 4개
token_embedding_layer.weight(50257,256)토큰 ID마다 256차원 벡터
token_embeddings(8,4,256)샘플 × 토큰 × 벡터 차원
torch.arange(max_length)[0,1,2,3]이번 입력 안의 위치 번호
pos_embedding_layer.weight(4,256)4개 위치의 학습 가능한 표
pos_embeddings(4,256)각 위치에 대응하는 벡터
input_embeddings(8,4,256)두 종류 벡터를 더한 최종 입력

50257은 이 GPT-2 인코딩의 어휘 크기이며 전체 글의 토큰 수가 아닙니다. context_length=max_length는 이 실습에서 둘을 같은 값으로 둔 것입니다. 함수의 기본 drop_last=True이므로 충분한 샘플이 있어야 배치 8개가 나옵니다.

3. shape가 다른데 어떻게 더할까요?

token_embeddings  (8, 4, 256)
pos_embeddings      (4, 256)
# 배치 축에 1이 있다고 생각하면
#                  (1, 4, 256)
# 같은 위치 벡터를 배치 8개 각각에 적용
result            (8, 4, 256)

이를 브로드캐스팅(broadcasting)이라고 합니다. 오른쪽 축부터 크기를 맞춰 같은 위치 벡터를 모든 샘플에 적용합니다. 이 경우 결과의 축이 늘거나 벡터 차원이 512로 합쳐지지 않습니다.

이 셀은 학습 가능한 위치 벡터를 더하는 방식입니다. 앞서 질문한 RoPE는 Query·Key를 회전시키는 방식이므로 구분하세요. targets는 이 셀에서 꺼냈지만 아직 임베딩하거나 손실 계산에 사용하지 않습니다.
교안에 저장된 세 출력
torch.Size([8, 4, 256])
torch.Size([4, 256])
torch.Size([8, 4, 256])

교안에 저장된 실행 결과와 위 shape 설명을 대조했습니다.

이 셀에는 원래 ???? 빈칸이 없습니다. 아래 빈칸 문제는 독립 코딩을 위한 추가 연습입니다. 이 수업의 범위는 여기까지이며, 다음 “Tokenizer 비교”는 포함하지 않습니다.

01 · 위치 번호 만들기

positions = torch.????(max_length)

시도 후 정답·해설

arange. 예: torch.arange(4)는 [0,1,2,3]을 담은 정수 텐서입니다.

02 · 위치 표의 행 개수

pos_embedding_layer = torch.nn.Embedding(????, output_dim)

시도 후 정답·해설

context_length. 예: context_length=4이면 0~3번 위치를 조회할 수 있습니다.

03 · 최종 결합 연산

input_embeddings = token_embeddings ???? pos_embeddings

시도 후 정답·해설

+. 이 교안은 같은 차원의 두 벡터를 원소별로 더합니다. 예: [1,2]+[0.1,0.2]=[1.1,2.2].

04 · 벡터 차원은?

(8,4,256) + (4,256)의 결과는 (8,4, ????)입니다.

시도 후 정답·해설

256. 브로드캐스팅으로 더하므로 벡터 길이는 256을 유지합니다.

05 · RoPE와 같을까?

“이 코드의 token_embeddings + pos_embeddings는 RoPE의 회전 계산이다.”

시도 후 정답·해설

X. 이 코드는 별도의 위치 임베딩을 더합니다. RoPE는 Query·Key를 회전시키는 방식입니다.

06 · 내 말로 설명하기

왜 위치 임베딩 shape에는 배치 크기 8이 없는데 토큰 임베딩에 더할 수 있나요?

작성 후 비교할 해설

브로드캐스팅으로 위치 벡터들을 모든 샘플에 공통 적용하기 때문입니다. 예: (2,4,3)+(4,3)도 (2,4,3)이며, 각각의 샘플에서 0번 위치에는 같은 0번 위치 벡터를 더합니다.

07 · 빈 노트북 실기

제출 위치: practice/day-01/position-embedding.ipynb. 폴더와 파일은 직접 만드세요. 예상 5분, PyTorch가 설치된 환경에서 진행합니다.

다운로드 없이 작은 크기로 연습합니다. 입력 [[1,2,3],[3,2,1]], 어휘 크기 6, 벡터 차원 4로 토큰 임베딩을 만들고 3개 위치의 임베딩을 더하세요. 세 shape를 예측하고 검사하세요.

시도 후 모범 코드
import torch

torch.manual_seed(123)
inputs = torch.tensor([[1,2,3],[3,2,1]])
token_layer = torch.nn.Embedding(6, 4)
position_layer = torch.nn.Embedding(3, 4)
token_vectors = token_layer(inputs)
position_vectors = position_layer(torch.arange(3))
combined = token_vectors + position_vectors
print(token_vectors.shape, position_vectors.shape, combined.shape)
assert tuple(token_vectors.shape) == (2, 3, 4)
assert tuple(position_vectors.shape) == (3, 4)
assert tuple(combined.shape) == (2, 3, 4)
assert torch.allclose(combined[0, 0],
                      token_vectors[0, 0] + position_vectors[0])

두 번째 샘플에도 같은 위치 벡터가 적용되는지 확인해 보세요. 합산은 벡터 차원을 늘리지 않습니다.
