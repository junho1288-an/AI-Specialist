batch 축·토큰 축·벡터 축을 구분하고 ca(batch)를 실행하기

기준: Chapter_3_Excercise_Attention.ipynb. 번호는 실행 횟수가 아니라 파일 위에서부터 센 셀 순서입니다. 자체 연습 문제이며 출제 여부는 강사 공지를 따릅니다.

Chapter 3 목차이전 수업확인 문제복습 카드

1. 여섯 토큰을 두 문장으로 쌓기

inputs의 각 행은 단어에 대응시킨 설명용 입력 벡터입니다. 이 셀에서 BPE나 학습된 임베딩을 실제로 계산한 것은 아닙니다.

inputs토큰 6개 × 벡터 3차원
(6,3)
→
stack(dim=0)동일 문장 2개
(2,6,3)
→
ca(batch)각 토큰에 새 벡터
(2,6,2)

예시: 두 장의 동일한 표를 새 축으로 쌓는 것이 stack입니다. cat으로 토큰 축을 이어 (12,3)으로 만드는 것과 다릅니다.

2. 빈칸 정답은 ca

ca = CausalAttention(d_in, d_out, context_length, 0.0)
context_vecs = ca(batch)

ca는 바로 위에서 만든 모듈 객체입니다. ca(batch)가 forward를 실행합니다. nn.Module의 호출 기능을 사용하므로 ca.forward(batch)를 직접 호출하는 것보다 일반적인 방식입니다.

코드값·뜻
inputs.shape[1]3: 한 토큰 벡터의 크기
batch.shape[1]6: 현재 토큰 개수
context_length6: 이번 예시에서는 최대 길이를 현재 길이와 같게 설정
d_out2: 출력 벡터 크기
dropout=0.0무작위 가중치 제거 없음

3. 같은 배치 두 장이면 왜 출력도 같을까?

동일한 입력에 동일한 파라미터를 적용하고 dropout=0이므로 두 배치 항목의 출력이 같습니다. batch 축끼리 Attention을 계산하는 것이 아니라 각 문장 안의 토큰들을 비교합니다.

첫 번째 토큰은 자신만 볼 수 있으므로 해당 가중치가 1입니다. 따라서 이 단일 헤드 셀에서는 첫 위치의 문맥 벡터가 첫 위치의 Value와 같습니다. Q·K가 사라진 게 아니라 참고할 후보가 하나뿐인 결과입니다.

저장된 출력과 현재 코드 모두 shape는 (2,6,2)입니다. 숫자 자체를 외우기보다 입력·출력의 세 축을 읽는 연습을 하세요.
시도 후 셀 2 전체 완성 코드 보기
import torch

inputs = torch.tensor(
  [[0.43, 0.15, 0.89], # Your     (x^1)
   [0.55, 0.87, 0.66], # journey  (x^2)
   [0.57, 0.85, 0.64], # starts   (x^3)
   [0.22, 0.58, 0.33], # with     (x^4)
   [0.77, 0.25, 0.10], # one      (x^5)
   [0.05, 0.80, 0.55]] # step     (x^6)
)

d_in = inputs.shape[1]   # 입력 차원 (d=3)
d_out = 2                # Q, K, V의 출력 차원 (d=2)

batch = torch.stack((inputs, inputs), dim=0)
torch.manual_seed(123)

context_length = batch.shape[1]

print("context_length:", context_length)

ca = CausalAttention(d_in, d_out, context_length, 0.0)
context_vecs = ca(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

원본 셀의 실행 코드에 정답만 채우고 주석을 줄인 버전입니다. 이전 셀의 import·클래스·batch에 의존하므로 순서대로 실행하세요. 원본 노트북은 수정하지 않았습니다.

06 · 내 말로 설명

첫 토큰의 문맥 벡터가 왜 그 토큰의 Value와 같을까요?

작성 후 비교할 해설

예: 첫 토큰에서 미래는 모두 가려져 자기 위치의 가중치만 1이고 나머지는 0입니다. 이 단일 헤드에는 추가 out_proj가 없어 그대로 해당 Value가 됩니다.

07 · 직접 코딩

제출: practice/day-01/run-causal.ipynb. 직접 파일을 만드세요. 예상 5~10분. 앞서 배운 클래스를 같은 노트북에서 먼저 정의하고 시작합니다.

첫 셀을 정의한 뒤 새로운 입력 (5,3)을 두 번 쌓아 (2,5,3)을 만들고 ca(3→2)를 적용하세요.

시도 후 확인 코드
torch.manual_seed(123)
inputs = torch.randn(5, 3)
batch = torch.stack((inputs, inputs), dim=0)
ca = CausalAttention(3, 2, context_length=5, dropout=0.0)
result = ca(batch)
assert tuple(batch.shape) == (2, 5, 3)
assert tuple(result.shape) == (2, 5, 2)
assert torch.allclose(result[0], result[1])
assert torch.allclose(result[:, 0], ca.W_value(batch)[:, 0])

동일한 두 입력은 동일한 출력을 가지며 첫 위치는 자기 Value만 반영합니다.
