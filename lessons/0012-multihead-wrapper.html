ModuleList와 cat으로 만드는 MultiHeadAttentionWrapper 이해

Chapter 3 목차이전 수업확인 문제복습 카드

1. 같은 문장을 여러 헤드가 읽습니다

Head(헤드)는 자기 Q·K·V 변환을 가진 Attention 계산 한 묶음입니다. 헤드마다 파라미터가 달라 서로 다른 방식으로 정보를 섞을 수 있습니다. 사람이 각 헤드의 의미를 미리 지정하는 것은 아닙니다.

같은 입력(2,6,3)
→
헤드 0 · 헤드 1각각 CausalAttention
각 출력 (2,6,2)
→
cat(dim=-1)마지막 벡터 축 연결
(2,6,4)

예시: 한 위치에서 헤드 0이 [1,2], 헤드 1이 [3,4]를 내면 이어 붙인 출력은 [1,2,3,4]입니다. 더한 [4,6]이나 평균 [2,3]이 아닙니다.

2. 핵심 코드 두 줄

self.heads = nn.ModuleList([
    CausalAttention(d_in, d_out, context_length, dropout, qkv_bias)
    for _ in range(num_heads)
])
# forward
return torch.cat([head(x) for head in self.heads], dim=-1)

ModuleList는 헤드들을 PyTorch의 하위 모듈로 등록합니다. 일반 Python 리스트에만 모듈을 넣으면 부모의 parameters()·state_dict()·to(device) 등이 그 모듈들을 자동 추적하지 못합니다. for문으로 각 헤드에 같은 x를 넣고 결과를 cat합니다.

이 Wrapper에서 d_out은 헤드 하나의 출력 차원입니다.
d_out=2, num_heads=2면 최종 차원은 4입니다. 다음 셀의 통합 구현에서는 d_out을 전체 출력 차원으로 쓰므로 반드시 구분해야 합니다.

이번 셀은 완성 코드여서 원래 ????는 없습니다. 두 헤드는 독립적으로 초기화된 가중치를 가지므로 같은 입력이어도 헤드 간 결과는 일반적으로 다릅니다. 이 Wrapper에는 합친 뒤의 out_proj가 없습니다.

시도 후 셀 3 전체 완성 코드 보기
class MultiHeadAttentionWrapper(nn.Module):

    def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
        super().__init__()
        self.heads = nn.ModuleList(
            [CausalAttention(d_in, d_out, context_length, dropout, qkv_bias)
             for _ in range(num_heads)]
        )

    def forward(self, x):
        return torch.cat([head(x) for head in self.heads], dim=-1)

torch.manual_seed(123)

context_length = batch.shape[1] # This is the number of tokens
d_in, d_out = 3, 2
mha = MultiHeadAttentionWrapper(
    d_in, d_out, context_length, 0.0, num_heads=2
)

context_vecs = mha(batch)

print(context_vecs)
print("context_vecs.shape:", context_vecs.shape)

01 · 모듈 목록 등록

self.heads = nn.????([...])

시도 후 정답·해설

ModuleList. ModuleList를 쓰면 각각의 헤드가 하위 모듈로 등록됩니다.

02 · 연결 함수

return torch.????([head(x) for head in self.heads], dim=-1)

시도 후 정답·해설

cat. 예: [1,2]와 [3,4]를 연결해 [1,2,3,4]로 만듭니다.

03 · Wrapper 출력 차원

헤드당 d_out=2, num_heads=3이면 최종 차원은?

시도 후 정답·해설

6. 각 헤드 출력 2개 값을 3개 헤드에서 연결해 6차원입니다.

04 · 이어 붙이는 축

torch.cat(head_outputs, dim=????)

마지막 벡터 축을 가리킬 숫자는?

시도 후 정답·해설

-1. 예: (2,6,2) 두 개를 마지막 축에 cat하면 (2,6,4)입니다.

05 · 파라미터 공유

“Wrapper 안의 모든 헤드는 하나의 동일한 W_query 객체를 공유한다.”

시도 후 정답·해설

X. 반복할 때마다 CausalAttention을 새로 만들어 각각의 레이어를 가집니다.

06 · 내 말로 설명

Wrapper에서 d_out=2, num_heads=2를 주었는데 출력이 4인 이유를 설명하세요.

작성 후 비교할 해설

각 헤드가 2차원 벡터를 만들고 마지막 축에 연결하므로 2×2=4입니다. 예: [1,2]와 [3,4]를 연결하면 길이 4입니다.

x = torch.randn(2, 4, 3)
wrapper = MultiHeadAttentionWrapper(3, 2, 4, 0.0, num_heads=3)

assert wrapper.heads[0].W_query is not wrapper.heads[1].W_query
