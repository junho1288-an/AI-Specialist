저장된 출력과 현재 코드가 다릅니다.

이 셀의 실행 코드는 d_out=2, num_heads=2이므로 현재 출력은 (2,6,2)가 맞습니다. 노트북에 남아 있는 (2,6,4) 출력은 현재 설정의 실행 결과로 볼 수 없습니다. shape 판단은 현재 코드로 하고 커널 재시작 후 다시 실행하세요.

1. d_out을 여러 헤드에 나눠 줍니다

이번 MultiHeadAttention의 d_out은 최종 전체 차원입니다. 전체 d_out=4, num_heads=2인 설명용 예라면 head_dim=2입니다. 교안 실제 호출의 d_out=2라면 head_dim=1입니다.

투영(B,T,d_out)
→
view + transpose(B,H,T,head_dim)
→
헤드별 계산scores (B,H,T,T)
→
합치기 + out_proj(B,T,d_out)

2. shape를 따라가면 코드가 보입니다

# 설명용 B=2, T=6, 전체 d_out=4, H=2
keys = self.W_key(x)                   # (2,6,4)
keys = keys.view(2, 6, 2, 2)            # (B,T,H,D)
keys = keys.transpose(1, 2)            # (2,2,6,2): (B,H,T,D)
# queries, values에도 같은 변환
attn_scores = queries @ keys.transpose(2, 3)  # (2,2,6,6)

view는 벡터의 마지막 축을 헤드 수와 헤드당 차원으로 나눕니다. transpose는 head 축을 앞으로 옮겨 각 헤드에서 토큰끼리 계산하게 합니다. 값의 총개수는 유지됩니다.

예시: 한 토큰의 벡터 [a,b,c,d]를 두 헤드로 나누면 헤드 0은 [a,b], 헤드 1은 [c,d]입니다. 각 헤드는 같은 전체 입력에서 서로 다른 학습 가능한 투영 결과를 받습니다.

3. 마스크와 합치기

attn_scores.masked_fill_(mask_bool, -torch.inf)
attn_weights = torch.softmax(
    attn_scores / keys.shape[-1]**0.5, dim=-1
)
context_vec = (attn_weights @ values).transpose(1, 2)
context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
context_vec = self.out_proj(context_vec)

keys.shape[-1]은 head_dim입니다. 전체 d_out의 제곱근이 아니라 각 헤드의 비교 차원으로 나눕니다. (T,T) 마스크는 batch와 head 축에 공통 적용됩니다.

transpose 뒤에는 메모리 배치가 바뀌어 view가 바로 불가능할 수 있어 contiguous()를 사용합니다. 헤드를 합친 뒤 out_proj는 마지막 차원을 다시 선형 변환해 헤드 정보를 섞습니다. 주석에 optional이라고 적혀 있어도 현재 구현은 항상 out_proj를 호출합니다.

구현d_out의 의미헤드 2개·d_out=2out_proj
Wrapper헤드 하나의 차원전체 출력 4없음
통합 구현전체 출력 차원헤드당 1, 전체 출력 2있음

차원을 공평하게 비교하려면 Wrapper의 헤드당 2·헤드 2개와 통합 구현의 전체 4·헤드 2개를 대응시킵니다. 파라미터와 out_proj까지 맞추지 않으면 숫자 출력이 같을 이유는 없습니다.

d_out % num_heads == 0은 마지막 축을 똑같이 나눌 수 있어야 한다는 조건입니다. 예: 전체 5차원은 헤드 2개로 균등하게 나눌 수 없어 assert에서 멈춥니다. num_heads는 양의 정수를 전제로 합니다.

시도 후 셀 4 전체 완성 코드 보기
class MultiHeadAttention(nn.Module):
    def __init__(self, d_in, d_out, context_length, dropout, num_heads, qkv_bias=False):
        super().__init__()
        assert (d_out % num_heads == 0), \
            "d_out must be divisible by num_heads"

        self.d_out = d_out
        self.num_heads = num_heads
        self.head_dim = d_out // num_heads # Reduce the projection dim to match desired output dim

        self.W_query = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_key = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.W_value = nn.Linear(d_in, d_out, bias=qkv_bias)
        self.out_proj = nn.Linear(d_out, d_out)  # Linear layer to combine head outputs
        self.dropout = nn.Dropout(dropout)
        self.register_buffer(
            "mask",
            torch.triu(torch.ones(context_length, context_length),
                       diagonal=1)
        )

    def forward(self, x):
        b, num_tokens, d_in = x.shape

        keys = self.W_key(x) # Shape: (b, num_tokens, d_out)
        queries = self.W_query(x)
        values = self.W_value(x)

        keys = keys.view(b, num_tokens, self.num_heads, self.head_dim)
        values = values.view(b, num_tokens, self.num_heads, self.head_dim)
        queries = queries.view(b, num_tokens, self.num_heads, self.head_dim)

        keys = keys.transpose(1, 2)
        queries = queries.transpose(1, 2)
        values = values.transpose(1, 2)

        attn_scores = queries @ keys.transpose(2, 3)  # Dot product for each head

        mask_bool = self.mask.bool()[:num_tokens, :num_tokens]

        attn_scores.masked_fill_(mask_bool, -torch.inf)

        attn_weights = torch.softmax(attn_scores / keys.shape[-1]**0.5, dim=-1)
        attn_weights = self.dropout(attn_weights)

        context_vec = (attn_weights @ values).transpose(1, 2)

        context_vec = context_vec.contiguous().view(b, num_tokens, self.d_out)
        context_vec = self.out_proj(context_vec) # optional projection

        return context_vec

02 · 현재 교안 출력

현재 호출 d_out=2, num_heads=2이면 최종 출력의 마지막 차원은?

2. 이 구현의 d_out은 전체 출력 차원입니다. 저장된 4와 구분하세요.

03 · 메모리 배치 준비

context_vec = context_vec.????().view(b, num_tokens, self.d_out)

시도 후 정답·해설

contiguous. transpose한 뒤 view에 맞는 연속적인 메모리 배치를 준비합니다.

04 · 스케일링에 쓸 차원

전체 8, 헤드 수 4이면 점수를 나눌 제곱근 안의 숫자는?

시도 후 정답·해설

2. 헤드당 Q·K 차원은 8/4=2이므로 sqrt(2)로 나눕니다.

05 · 이름이 같은 d_out

“Wrapper와 통합 구현에서 d_out은 항상 같은 의미다.”

시도 후 정답·해설

X. Wrapper는 헤드당 차원, 통합 구현은 최종 전체 차원으로 사용합니다.

06 · 내 말로 설명

view와 transpose는 각각 무엇을 바꾸며, out_proj는 왜 마지막 차원을 늘리지 않나요?

작성 후 비교할 해설

예: (2,6,4)를 view로 (2,6,2,2)로 나누고 transpose로 (2,2,6,2)로 축을 바꿉니다. out_proj는 Linear(d_out,d_out)이라 마지막 크기는 유지하면서 값들을 섞습니다.
