셀 번호는 파일 위에서부터 센 순서입니다. 자체 연습 문제이며 실제 출제 범위는 강사 공지를 따릅니다.

Chapter 4 목차이전확인 문제복습 카드

1. 마지막 실행 흐름

설정 + GPTModel무작위 초기화
→
문장 encodeID 리스트
→
unsqueeze(0)(1,T) 입력
→
생성 + decode새 ID와 문자열

예시: 교안 저장 출력에서 “Hello, I am”은 ID 4개입니다. 여기에 토큰 10개를 생성하므로 최종 길이는 14입니다. 영어 단어 10개나 글자 10개를 추가한다는 뜻이 아닙니다.

2. config 읽기

키교안 값의미
vocab_size50257GPT-2 인코딩 어휘 크기
context_length1024모델이 한 번에 참고할 최대 토큰 길이
emb_dim768토큰 벡터 크기
n_heads12Attention 헤드 수, 헤드당 64차원
n_layers12TransformerBlock 개수
drop_rate0.1dropout 확률
qkv_biasFalseQ·K·V Linear 편향 사용 안 함

3. 배치 축을 넣고 빼기

encoded = tokenizer.encode(start_context)  # 리스트
encoded_tensor = torch.tensor(encoded).unsqueeze(0)  # (T,) → (1,T)
out = generate_text_simple(model, encoded_tensor, 10, context_length)
decoded_text = tokenizer.decode(out.squeeze(0).tolist())

모델은 (배치, 길이)를 받으므로 문장 하나에도 배치 축이 필요합니다. 생성 후 squeeze(0)로 크기 1인 배치 축을 없애고 tolist()로 decode가 받을 ID 리스트를 만듭니다.

GPTModel(config)는 학습된 GPT-2 로딩이 아닙니다.

이 노트북에는 사전학습 가중치를 불러오거나 optimizer로 학습하는 과정이 없습니다. tokenizer는 준비된 것을 사용하지만 모델 가중치는 무작위입니다. 따라서 저장 출력처럼 어색한 문장이 나오는 것은 예상 가능한 결과입니다.

이 셀은 “GPT_CONFIG_124M”이라는 이름으로 GPT-2 Small 형태의 설정을 사용합니다. 이름만으로 실제 파라미터 수나 사전학습 완료를 보장하지 않습니다. 이 구현은 입력 임베딩과 출력 가중치를 공유하지 않으므로 가중치를 공유하는 구현과 파라미터 수가 다를 수 있습니다.

torch.manual_seed(123)은 같은 조건에서 초기화 재현을 돕습니다. model.eval()은 dropout을 끕니다. 이것들이 학습을 수행하거나 문장을 유창하게 만드는 것은 아닙니다.

4. 작은 모델부터 확인하기

전체 설정은 메모리와 실행 시간이 더 필요하므로 아래 과제는 작은 설정을 사용합니다. 어휘 크기를 줄인 모델에는 실제 GPT-2 토큰 ID를 그대로 넣지 말고 범위 내의 연습용 ID를 넣으세요.

시도 후 셀 6 전체 완성 코드 보기
def main():
    GPT_CONFIG_124M = {
        "vocab_size": 50257,     # 단어 집합 크기
        "context_length": 1024,  # 최대 문맥 길이
        "emb_dim": 768,          # 임베딩 차원
        "n_heads": 12,           # 어텐션 헤드 수
        "n_layers": 12,          # 레이어 수
        "drop_rate": 0.1,        # 드롭아웃 비율
        "qkv_bias": False        # Q,K,V 편향 사용 여부
    }

    torch.manual_seed(123)

    model = GPTModel(GPT_CONFIG_124M)
    model.eval()

    start_context = "Hello, I am"

    tokenizer = tiktoken.get_encoding("gpt2")
    encoded = tokenizer.encode(start_context)
    encoded_tensor = torch.tensor(encoded).unsqueeze(0) # 배치 차원 추가

    print(f"\n{50*'='}\n{22*' '}IN\n{50*'='}")
    print("\nInput text:", start_context)
    print("Encoded input text:", encoded)
    print("encoded_tensor.shape:", encoded_tensor.shape)

    out = generate_text_simple(
        model=model,
        idx=encoded_tensor,
        max_new_tokens=10,  # 10개의 새로운 토큰 생성
        context_size=GPT_CONFIG_124M["context_length"]
    )

    decoded_text = tokenizer.decode(out.squeeze(0).tolist())

    print(f"\n\n{50*'='}\n{22*' '}OUT\n{50*'='}")
    print("\nOutput:", out)
    print("Output length:", len(out[0]))
    print("Output text:", decoded_text)

if __name__ == "__main__":
    main()

01 · 배치 축 추가

encoded_tensor = torch.tensor(encoded).????(0)

시도 후 정답·해설

unsqueeze. 예: (4,)를 (1,4)로 바꿉니다.

02 · 배치 축 제거

out.????(0).tolist()

시도 후 정답·해설

squeeze. 배치 크기가 1일 때 (1,T)를 (T,)로 바꿉니다.

03 · 최종 길이

초기 토큰 4개에 새 토큰 10개를 생성하면 전체 토큰 수는?

시도 후 정답·해설

14. 이 함수는 초기 ID를 유지하고 10개를 붙입니다.

04 · 평가 모드

model.????()  # dropout 비활성화

시도 후 정답·해설

eval. eval은 dropout을 비활성화하지만 무작위 가중치를 학습하지 않습니다.

05 · 사전학습 여부

“GPT_CONFIG_124M으로 GPTModel을 만들면 학습된 GPT-2 가중치가 자동 다운로드된다.”

시도 후 정답·해설

X. 이 코드에는 학습된 가중치를 로드하는 동작이 없습니다.

06 · 내 말로 설명

어색한 출력이 반드시 버그는 아닌 이유와 tokenizer와 모델의 준비 상태를 설명하세요.

작성 후 비교할 해설

tokenizer는 이미 정해진 규칙을 쓰지만 GPTModel의 가중치는 처음 초기화한 상태입니다. 예: ID로 변환·생성·복원이 동작해도 자연스러운 문장 생성 능력은 별도 학습이 필요합니다.

tiny_cfg = {
    "vocab_size": 32, "context_length": 8, "emb_dim": 8,
    "n_heads": 2, "n_layers": 2, "drop_rate": 0.0, "qkv_bias": False
}
model = GPTModel(tiny_cfg)
assert model.training
model.eval()
assert not model.training
idx = torch.tensor([1,2,3]).unsqueeze(0)
with torch.no_grad():
    logits = model(idx)
assert not logits.requires_grad
out = generate_text_simple(model, idx, 2, context_size=8)

ids = out.squeeze(0).tolist()
