Tokenizer 비교가 시작되기 전,
교안의 코드 셀 7개를 순서대로 연습합니다.

각 수업은 짧은 설명과 그림 → 자동 확인 문제 → 직접 코딩 과제로 구성했습니다. 정답은 먼저 시도한 뒤 열어 보세요. 설명 가리기 버튼으로 기억해서 풀 수 있습니다.

교안 코드 셀HTML 수업핵심 목표
1BPE · encode/decode문자열 ↔ 토큰 ID
2파일 준비와 한 칸 shift입력과 다음 토큰 정답
3GPTDatasetV1샘플 생성·개수·조회
4DataLoader 만들기샘플을 배치로 묶기
5iter · next로 배치 읽기입력·정답 꺼내기
6토큰 임베딩ID를 학습 가능한 벡터로
7위치 임베딩위치 정보를 더해 모델 입력 완성
최종 shape 흐름

문자열 → 토큰 ID 리스트 → 길이 4의 입력·정답 샘플 → 배치 (8,4) → 토큰 벡터 (8,4,256) → 위치 벡터 (4,256)를 더해 (8,4,256).

오늘은 한 번에 전부 외우기보다 수업 한 개씩 학습하고 자료 없이 재작성하세요. 실제 출제 범위는 강사 공지를 따릅니다. Tokenizer 비교 셀은 이 목차의 범위에 포함하지 않았습니다.
