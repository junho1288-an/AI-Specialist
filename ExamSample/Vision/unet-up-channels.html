채널은 “특징맵이 몇 장인가?”입니다

교안 81쪽처럼 블록 위 숫자 = 채널 수, 아래 숫자 = 공간 크기입니다. B=1로 고정합니다. 블록은 이미지 속 물체가 아니라 텐서를 나타냅니다.

공통 설정: Up(in_channels=8, out_channels=2) · skip은 (1,4,10,10).
이때 Up의 in_channels=8은 concat 후 DoubleConv가 받는 채널 수입니다. True의 x1 입력은4채널, False의 x1 입력은8채널입니다.

① bilinear=True

Upsample(×2) → concat → DoubleConv(8,2,mid_channels=4)

DoubleConv 내부: Conv2d(8,4,3,padding=1) → ReLU → Conv2d(4,2,3,padding=1) → ReLU

첫 Conv가 8장의 정보를 섞어 4장을 만들고, 둘째 Conv가 4장의 정보를 섞어 2장을 만듭니다. 단순히 앞쪽 채널을 잘라 남기는 것이 아닙니다.

② bilinear=False

ConvTranspose2d(8,4,kernel_size=2,stride=2) → concat → DoubleConv(8,2)

DoubleConv 내부: Conv2d(8,2,3,padding=1) → ReLU → Conv2d(2,2,3,padding=1) → ReLU

mid_channels를 생략하면 DoubleConv 내부에서 mid_channels=out_channels가 되어 MID=2입니다. 두 번째 Conv는 채널 수가 같아도 새 weight로 값을 계산합니다.

IN · MID · OUT은 어디를 부르는가?

IN: 첫 Conv 입력MID: 첫 Conv 출력 / 둘째 Conv 입력OUT: 둘째 Conv 출력
True8채널4채널2채널
False8채널2채널2채널

MID라는 별도 레이어를 추가하는 게 아닙니다. 두 Conv 사이의 텐서가 몇 채널인지 정하는 숫자입니다. 두 경우 모두 최종 shape는 (1,2,10,10)입니다.

확인 문제: True에서 out_channels만3으로 바꾸면?

IN=8 → MID=4 → OUT=3. mid_channels는 in_channels//2로 명시했으므로4를 유지합니다. 최종 shape=(1,3,10,10).

교안 그림과 현재 코드의 차이
PDF 81쪽: padding 없음 → Conv3×3마다 H,W가2씩 감소.
실습 DoubleConv: padding=1,stride=1 → Conv 뒤에도 H,W 유지.
이 예시는 업샘플 출력과 skip의 공간 크기가 같아 F.pad로 추가할 칸이 없습니다.
