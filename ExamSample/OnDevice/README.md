# On-device 빈칸 모음

[통합 노트북](ondevice-exercises.ipynb)을 열어 준비 셀을 실행하세요. 문제 코드 → 바로 아래 검증 셀 순서로 진행합니다. `# ????`가 붙은 `missing()`을 올바른 식/문장으로 바꿉니다. 정답은 각 문제 아래 접힌 해설에 있습니다.

- 필요 환경: Python + PyTorch(CPU 가능). 설치·네트워크 호출은 노트북에 없습니다.
- 원본 1~5번 AVD의 영어/한국어 실습 마커를 전수 대조했습니다. 총 32개 구간입니다. 다운로드와 긴 외부 실행은 제외했습니다.
- 원본 바깥 문맥을 함수 인자로 옮기고 테스트용 반환문을 추가했습니다. codebook 중심 갱신은 전체 k 반복을 포함합니다.
- KD는 학습 루프의 한 배치 손실 부분만 검사하며 teacher gradient 없음과 student gradient 생성을 확인합니다. CPU를 위해 .cuda()를 .to(inputs.device)로 바꿨습니다.
- KMeans는 군집 알고리즘 대신 클러스터 수·주어진 코드북 복원·평균 갱신을 검사합니다.
- AWQ의 pseudo quantizer는 고정 .25 간격 더미입니다. 실제 그룹 양자화 품질을 측정하지 않습니다.
- EAGLE/DFlash/LLM은 인자와 작은 텐서 결과를 검사하는 더미로 대체했습니다. 모델 정확도·처리속도·통합 추론 검사는 아닙니다.
- pruning은 k>=1, 동점 없는 입력, H2O는 recent_size>0, SnapKV는 양수 window·홀수 kernel 조건입니다.
- 각 문제 답안을 실제 테스트 셀로 실행하고 None 오답이 거절되는지 확인했습니다. 검증 기록: [validation.json](validation.json).
- 생성/재검증: `python build_exercises.py` (nbformat 추가 필요). 재생성하면 작성한 답이 덮어써지므로 학습 중 실행하지 마세요.
