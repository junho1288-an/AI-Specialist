[통합 노트북](llm-exercises.ipynb)을 열어 준비 셀 → 문제 코드 → 검증 코드 순서로 실행하세요. `MISSING`은 원본 `???`입니다. 정답으로 교체하고 함수 셀부터 재실행하세요. 해설·답은 각 문제 아래 접혀 있습니다.

- 지정한 6개 파일의 코드상 빈칸 89개를 26문제로 묶었습니다. 주석 속 ???는 세지 않습니다.
- CPU PyTorch만 필요합니다. 다운로드·모델 체크포인트·tiktoken·pandas 없이 실행합니다.
- 더미 토크나이저는 UTF-8 바이트 인코딩입니다. 실제 BPE 분할 품질·ID는 평가하지 않고 encode/decode 호출과 텐서 흐름만 검사합니다.
- 분류의 pandas iloc는 작은 더미로 대체했습니다. Chapter2 Tokenizer 비교 이후는 기존 시험 범위에 따라 제외했습니다.
- Attention과 GPT는 원본 소형 구조를 사용합니다. 생성은 다음 ID를 예측하는 더미 모델입니다.
- Chapter5 원본 generate는 주석과 달리 top-k/temperature 구현이 없으며 greedy입니다. EOS 테스트는 원본 조건문에 맞춰 배치1, EOS를 붙이기 전 종료합니다.
- 학습은 두 배치만 실행하여 zero_grad와 업데이트를 검증합니다. LoRA는 B를 비영 값으로 바꿔 수식·gradient·동결 범위를 검사합니다.
- 원본 클래스/함수의 중복 구현은 제공 보조 코드로 두어 문제끼리 독립적입니다. 실제 다운로드·전체 사전학습·평가 품질은 검사하지 않습니다.
- 참고 답안은 별도 공식 답안 파일이 아니라 원본 힌트·수식으로 작성했습니다. 원본 파일은 변경하지 않았습니다.
